# 实战建站：用 AI 快速搭建企业官网、产品营销站、外贸独立站

## AI 建站的两种路线

| 路线 | 工具 | 适合人群 | 上线速度 |
|------|------|----------|----------|
| AI 生成代码 + 自行部署 | ChatGPT/Claude + Vercel | 懂一点技术 | 1-2 天 |
| AI 建站平台 | Bolt.new/v0/Cursor | 新手友好 | 几小时 |
| AI + CMS | WordPress + AI 插件 | 需要后台管理 | 2-3 天 |

本文以 **AI 生成代码路线** 为主，覆盖三种典型建站场景。

## 场景一：企业官网

### Step 1：明确网站结构

```
请帮我规划一个科技公司企业官网的页面结构，要求：
- 首页（Hero + 核心业务 + 客户数据 + 合作品牌）
- 关于我们（公司简介 + 团队展示 + 发展历程）
- 产品中心（3-5 款产品，卡片式展示）
- 解决方案（按行业分类，2-3 个行业）
- 联系我们（表单 + 地图 + 联系方式）

请输出每个页面需要的内容模块清单。
```

### Step 2：生成首页代码

```
请用 HTML + Tailwind CSS 生成企业官网首页，要求：
1. 固定顶部导航栏（Logo + 导航链接 + "联系我们"按钮）
2. Hero 区：全屏背景图（使用 picsum 占位图），中央大标题 + 副标题 + CTA 按钮
3. 数据展示区："服务 500+ 企业"、"10 年行业经验"、"99.9% 系统可用性" 三组数据
4. 核心业务区：3 个业务方向卡片，每个有图标+标题+描述
5. 合作品牌区：6 个品牌 Logo 横排展示
6. Footer：四列布局（公司信息、产品、解决方案、联系方式）

配色：主色 #2563eb（蓝色），辅助色 #f8fafc（浅灰背景），文字 #1e293b
请输出完整 HTML 文件，使用 Tailwind CDN。
```

### Step 3：部署上线

```bash
# 1. 创建项目目录
mkdir my-company-site && cd my-company-site

# 2. 把 AI 生成的代码保存为 index.html

# 3. 部署到 Vercel（免费）
npx vercel --prod

# 4. 绑定自定义域名（在 Vercel 后台操作）
```

## 场景二：产品营销落地页

### Prompt 模板

```
请生成一个 SaaS 产品营销落地页，产品信息如下：
- 产品名：SmartFlow 智能工作流
- 定位：企业级自动化工作流平台
- 核心卖点：零代码搭建、AI 自动决策、实时数据看板
- 目标用户：中小企业运营团队
- 价格：免费版 / 专业版 ¥299/月 / 企业版定制

页面结构：
1. Hero 区：产品 Slogan + 价值主张 + "免费试用"按钮 + 产品截图
2. 痛点区：3 个用户常见痛点 → 产品如何解决
3. 功能展示区：左侧功能截图 + 右侧文字说明，交替排列
4. 客户评价区：3 条客户推荐语
5. 价格对比区：三栏定价表
6. FAQ 区：5 个常见问题折叠面板
7. 底部 CTA：再次强调核心价值 + 注册表单

风格参考 Notion 官网，简洁现代。
```

### 转化率优化 Prompt

```
请基于以上落地页，添加以下转化优化元素：
1. 导航栏固定在顶部，滚动时显示"免费试用"按钮
2. Hero 区添加社会证明："已有 2000+ 团队在使用"
3. 价格区"专业版"卡片高亮为推荐方案
4. 页面底部添加倒计时："限时优惠还剩 X 天"（JS 动态计算）
5. 所有 CTA 按钮点击后弹出简洁的注册表单（邮箱 + 密码）
```

## 场景三：外贸独立站

### 多语言 + SEO + 支付集成

```
请生成一个外贸 B2B 独立站首页，产品为 LED 照明灯具，面向欧美市场。

要求：
1. 英文内容，专业商务英语风格
2. Hero 区突出工厂直供、OEM/ODM 能力
3. 产品分类展示：室内照明、户外照明、商业照明
4. 公司实力展示：工厂照片区、认证展示（CE/RoHS/UL）
5. 客户评价（欧美客户名称和公司）
6. 询盘表单（Name, Email, Company, Product Interest, Message）
7. 页脚包含公司地址（中国深圳）、社交媒体链接

SEO 要求：
- Title: "LED Lighting Manufacturer & Supplier | [Company Name]"
- 包含 JSON-LD Organization 结构化数据
- 所有图片添加描述性 alt 文本
- H1 标签包含核心关键词

请输出完整 HTML + Tailwind CSS 代码。
```

### 外贸站必备功能 Checklist

| 功能 | 实现方式 | AI 能帮什么 |
|------|----------|------------|
| 多语言 | 英文为主 + 小语种 | AI 翻译全部文案 |
| SEO | Meta + Schema + Sitemap | AI 生成全套 SEO 配置 |
| 询盘表单 | Formspree/自建后端 | AI 生成表单+验证代码 |
| 在线客服 | WhatsApp/Tawk.to 嵌入 | AI 生成嵌入代码 |
| 支付 | Stripe/PayPal | AI 生成支付集成代码 |
| 分析 | Google Analytics | AI 生成 GA4 埋点代码 |

## 常见问题

**Q：AI 生成的页面能直接商用吗？**
可以。代码本身无版权问题，但占位图片和文案需替换为自己的内容。

**Q：后续维护怎么办？**
把需求描述给 AI 即可，如"在产品区和 Footer 之间加一个新闻动态区，展示最近 3 篇文章"。

**Q：需要域名和服务器吗？**
域名建议购买（¥50-100/年）。服务器用 Vercel/Netlify 免费方案即可，无需购买服务器。
