# 提效利器：编写批量数据处理、重复操作自动化脚本

## 哪些工作适合自动化？

| 特征 | 举例 | 自动化价值 |
|------|------|-----------|
| 每天重复做 | 整理报表、发通知邮件 | ⭐⭐⭐ |
| 格式固定、量大 | 批量改文件名、转换格式 | ⭐⭐⭐ |
| 多步骤串联 | 数据下载→清洗→分析→发邮件 | ⭐⭐⭐ |
| 偶尔做但很繁琐 | 合并 50 个 Excel、批量加水印 | ⭐⭐ |
| 需要创造力 | 写方案、做设计 | ❌ |

**判断标准：** 如果你能写出标准操作步骤（SOP），就能让 AI 帮你自动化。

## 实战一：批量文件处理

### 场景：批量处理 Excel 报表

```
请写一个 Python 脚本，实现以下功能：
1. 读取 data 文件夹下所有 .xlsx 文件
2. 每个文件都有"日期"、"产品"、"销量"、"金额"四列
3. 合并所有文件到一个 DataFrame
4. 按"产品"分组汇总：总销量、总金额、平均单价
5. 按月统计趋势
6. 结果保存到 summary.xlsx，包含：
   - Sheet1：产品汇总表
   - Sheet2：月度趋势表
7. 使用 pandas + openpyxl
```

### 场景：批量图片处理

```
写一个 Python 脚本：
1. 扫描 images/ 文件夹下的所有 jpg/png 文件
2. 将每张图片调整为：
   - 宽度统一为 800px，高度按比例缩放
   - 压缩质量设为 85
   - 添加白色水印文字 "© 2026 MyBrand"，右下角
3. 处理后的图片保存到 output/ 文件夹
4. 保持原文件名
5. 打印处理进度：已处理 X/Y 张

使用 Pillow 库。
```

## 实战二：RPA 式自动化（操控软件）

### 用 pyautogui 自动化桌面操作

```
写一个 Python 脚本，自动化以下操作：
1. 打开 Chrome 浏览器
2. 访问某个后台管理系统（URL 我来配置）
3. 自动登录（用户名密码从配置文件读取）
4. 点击"导出报表"按钮
5. 等待下载完成（检测下载文件夹是否有新文件）
6. 将下载的文件移动到指定目录并重命名

使用 pyautogui + pyperclip，加上每步之间的等待时间和屏幕截图确认。
需要配置文件 config.json 存储 URL、用户名等敏感信息。
```

## 实战三：自动化工作流串联

### 场景：每日数据报表自动生成+发送

```
写一个 Python 脚本，实现每日自动化报表流程：

步骤一：数据采集
- 从数据库查询昨日的销售数据（使用 pymysql）

步骤二：数据处理
- 计算日销售额、订单数、客单价
- 与前日对比计算环比增长率
- 按 TOP 10 热销产品排名

步骤三：生成报告
- 用 pandas 生成 Excel 报表
- 用 matplotlib 生成趋势图保存为 PNG
- 用 jinja2 模板生成 HTML 格式的邮件正文

步骤四：发送邮件
- 收件人：team@company.com
- 主题：每日销售报表 - {日期}
- 正文：HTML 格式，嵌入关键数据和趋势图
- 附件：Excel 报表

步骤五：记录日志
- 写入 log.txt：执行时间、数据条数、发送状态

脚本需要通过 crontab 每天早上 8:00 自动执行。
请提供 crontab 配置方法。
```

### crontab 配置

```bash
# 编辑定时任务
crontab -e

# 每天早上 8 点执行
0 8 * * * cd /home/user/scripts && /usr/bin/python3 daily_report.py >> /home/user/scripts/log.txt 2>&1
```

## 实战四：拿来就用的自动化脚本模板

### 文件夹监控+自动处理

```
写一个 Python 脚本，监控指定文件夹：
1. 使用 watchdog 库监听文件夹变化
2. 当有新的 .csv 文件进入时：
   - 自动读取并验证格式
   - 清洗数据（去重、填空值）
   - 导入数据库
   - 原文件移到 archive/ 子文件夹
   - 发送通知："已处理文件 xxx，共 N 条数据"
3. 如果格式异常，移到 error/ 子文件夹并通知
```

## 常见问题

**Q：脚本在别人电脑上跑不了？**
让 AI 帮你生成 `requirements.txt` 和一个 README，写明安装步骤。

**Q：自动化脚本出错怎么办？**
每步都加 try-except 和日志记录，出错时发通知，不要静默失败。

**Q：定时任务在电脑关机时不执行？**
部署到云服务器（最低配即可，约 ¥30/月），7×24 运行。
