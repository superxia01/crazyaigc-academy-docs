# 脚本与分镜拆解：AI 生成视频脚本并同步转化为视觉分镜画面

视频制作最耗时的不是拍摄或剪辑，而是前期策划。一个 60 秒的短视频，写脚本、画分镜可能要花 2-3 小时。AI 可以把这个过程压缩到 15 分钟。

## 传统流程 vs AI 辅助流程

```
传统流程（3-5 小时）：
确定选题 → 写脚本 → 画分镜 → 找参考图 → 确认方案

AI 辅助流程（15-30 分钟）：
确定选题 → AI 生成脚本 → AI 生成分镜画面 → 微调确认
```

## 第一步：AI 生成视频脚本

### 用 ChatGPT/Claude 生成结构化脚本

```
提示词模板：

"请为我写一个 [时长] 秒的 [平台] 短视频脚本。

产品/主题：[你的产品或主题]
目标受众：[目标用户画像]
核心卖点：[1-3 个核心卖点]
风格调性：[如：轻松幽默/专业可信/温暖感人]

输出格式要求：
1. 按分镜编号，每个分镜包含：
   - 时长（秒）
   - 画面描述（具体的视觉内容）
   - 旁白/字幕文案
   - 背景音乐/音效建议
   - 镜头运动方式
2. 开头 3 秒必须有强烈的注意力钩子
3. 结尾有明确的 CTA（行动召唤）"
```

### 脚本示例（60 秒护肤品短视频）

```
分镜 1（0-3 秒）| 注意力钩子
画面：一位女性对着镜子，看到眼下细纹，轻轻叹气
旁白："熬夜留下的痕迹，不只是黑眼圈。"
镜头：特写 → 缓慢拉远
音效：轻柔的钢琴音

分镜 2（3-8 秒）| 痛点放大
画面：快节奏切换——加班、看手机、咖啡杯堆积
旁白："加班、刷剧、带娃……眼周肌肤每天承受 10000 次微表情。"
镜头：快速蒙太奇
音效：时钟滴答声

分镜 3（8-18 秒）| 产品引入
画面：产品从水中缓缓浮出，水珠滑过瓶身
旁白："XX 眼霜，专为亚洲女性研制的夜间修护方案。"
镜头：360 度环绕产品
音效：水滴声

分镜 4（18-30 秒）| 成分与功效
画面：成分动画——角鲨烷分子、胶原蛋白结构
旁白："核心成分角鲨烷 + 三重胶原肽，48 小时深层修护。"
镜头：微距 → 动画演示
音效：科技感音效

分镜 5（30-45 秒）| 使用场景
画面：睡前护肤流程——涂抹眼霜、轻拍吸收
旁白："每晚 30 秒，温和不刺激。7 天淡化细纹，28 天重塑眼周。"
镜头：中景 → 特写手部动作
音效：舒缓音乐

分镜 6（45-55 秒）| 效果对比
画面：使用前后的眼周状态对比（真实拍摄素材）
旁白："真实用户反馈，95% 表示眼周明显改善。"
镜头：并排对比
音效：叮的提示音

分镜 7（55-60 秒）| CTA
画面：产品 + 促销信息 + 购买按钮动画
旁白："限时买一送一，点击下方链接，今晚就开始修护。"
镜头：产品居中 + 文字动画
音效：CTA 音效
```

## 第二步：AI 生成分镜画面

### 用 AI 图像工具将每个分镜转化为参考图

```
分镜 1 的画面提示词：
A young Asian woman looking in a bathroom mirror,
touching under her eyes with a concerned expression,
soft bathroom lighting, intimate close-up,
cinematic color grading, shallow depth of field

分镜 3 的画面提示词：
A luxury eye cream bottle slowly emerging from water,
water droplets sliding down the glass surface,
dramatic studio lighting, macro product photography,
premium skincare aesthetic, dark background
```

### Midjourney 批量生成分镜图

```
# 用 --sref 保持所有分镜的视觉风格统一
# 先选一张定调的参考图

分镜1 --sref [风格参考URL] --sv 400 --ar 16:9 --v 6.1
分镜2 --sref [风格参考URL] --sv 400 --ar 16:9 --v 6.1
分镜3 --sref [风格参考URL] --sv 400 --ar 16:9 --v 6.1
...

# --ar 16:9 视频常用比例
# --sv 400 中等风格强度，保证统一但不死板
```

### 分镜画面一致性技巧

```
技巧一：统一色调
所有分镜图使用相同的色调关键词
如："warm golden tones" 或 "cool blue tones"

技巧二：统一角色
主角分镜使用 --cref 保持人物一致
非人物分镜不需要

技巧三：统一画幅
所有分镜使用相同的 --ar 参数
建议 16:9（横屏）或 9:16（竖屏短视频）
```

## 第三步：制作分镜板（Storyboard）

### 用 Canva 排列分镜

```
操作步骤：
1. 在 Canva 中选择「视频分镜模板」
2. 将 AI 生成的分镜图逐张放入
3. 在每张图下方标注：
   - 分镜编号
   - 时长
   - 旁白文案
   - 镜头运动方式
4. 导出为 PDF 分镜板
```

### 用 ChatGPT 生成分镜表格

```
提示词：
"请将上面的脚本转化为一个 Markdown 表格，列包括：
分镜编号 | 时长 | 画面描述 | 旁白文案 | 镜头运动 | 备注"

输出后可以直接粘贴到文档中作为分镜板。
```

## 分镜到成片的衔接

分镜确定后，进入制作阶段：

```
分镜板确认
    ↓
按分镜准备素材
    ├── AI 生成画面 → 图片类视频
    ├── AI 生成视频 → 动态视频（Sora/Runway/Kling）
    ├── 实拍素材 → 拍摄计划
    └── 混合模式 → 部分实拍 + 部分 AI

    ↓
剪辑合成（CapCut/Premiere）
    ↓
添加配音和字幕
    ↓
输出成片
```

## 常见问题

**Q：AI 生成的分镜图和实际成片差距很大？**
分镜图的作用是确定构图和色调方向，不需要和成片一模一样。重点传达「画面里有什么」和「什么氛围」。

**Q：脚本文案可以用 AI 生成后直接用吗？**
建议作为初稿，人工审核修改。AI 生成的文案容易过于模板化，需要加入品牌独有的语言风格和真实数据。

**Q：一个 3 分钟的视频需要多少个分镜？**
一般 3 分钟视频需要 15-25 个分镜，每个分镜 7-12 秒。节奏快的视频分镜多一些，节奏慢的分镜少一些。
