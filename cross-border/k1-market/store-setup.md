# 店铺起步：店铺注册规范、Listing 埋词优化、转化率核心因素拆解

开店不是注册个账号就完事了。从店铺资质准备到 Listing 上架优化，每一步都影响你后续的流量和转化。本章从注册到上架，用 AI 辅助你高效完成「开店即起飞」。

## 一、各平台开店规范速查

### 1.1 Amazon 开店核心要求

| 项目 | 要求 | 注意事项 |
|------|------|---------|
| 营业执照 | 中国大陆/港澳台 | 建议用公司执照，个体户限制多 |
| 双币信用卡 | Visa/Mastercard | 用于扣月租和广告费 |
| 银行账户 | 第三方收款（万里汇/Payoneer） | 提前开户，审核需 3-5 天 |
| 身份验证 | 法人身份证+营业执照 | 确保信息一致 |
| 收款账号 | 支持美元/欧元收款 | 推荐万里汇、PingPong |
| 月租费 | 美国 $39.99/月 | 专业卖家计划 |
| 审核 | 视频验证+地址验证 | 准备好水电账单 |

### 1.2 TikTok Shop 开店要点

| 项目 | 要求 |
|------|------|
| 主体资质 | 中国营业执照（个体户也可） |
| 商品品类 | 部分品类需定向邀约 |
| 物流 | 平台物流（FBT）或自发货 |
| 保证金 | 按品类 $100-500 |
| 美区门槛 | 需要美国本土主体或特定资质 |

## 二、AI 辅助 Listing 优化全流程

### 2.1 关键词挖掘与分层

Listing 优化的核心是**关键词布局**——不同位置的关键词权重不同：

| 位置 | 权重 | 建议策略 |
|------|------|---------|
| 标题（Title） | ⭐⭐⭐⭐⭐ | 核心大词 + 主要长尾词 |
| 五点描述（Bullets） | ⭐⭐⭐⭐ | 卖点词 + 使用场景词 |
| 产品描述（Description） | ⭐⭐⭐ | 补充长尾词、同义词 |
| Search Terms | ⭐⭐⭐ | 未覆盖的词放这里 |
| A+ 页面 | ⭐⭐ | 品牌词 + 场景词 |

**关键词分层 Prompt：**

```text
请对以下关键词进行分层，用于 Amazon Listing 优化：

关键词列表：wireless earbuds, bluetooth earphones, noise cancelling earbuds,
earbuds wireless, bluetooth headset, wireless headphones, running earbuds,
gym earphones, IPX7 earbuds, ANC earbuds, earbuds for iPhone, android earbuds

分层标准：
1. 核心词（3-5个）：搜索量最大，必须出现在标题前60字符
2. 次核心词（5-8个）：重要长尾词，分布到标题后半段和五点描述
3. 补充词（剩余）：放入 Search Terms 和描述中
4. 否定词：不相关或竞争过大的词，标记排除

输出格式：分层表格，包含搜索量级估算和布局位置建议
```

### 2.2 标题公式

**Amazon 高权重标题公式：**

```
品牌名 + 核心关键词 + 核心卖点1 + 核心卖点2 + 适用场景/兼容性 + 颜色/尺寸

示例：
SoundMax Wireless Earbuds Bluetooth 5.3 Headphones, 40H Battery Life,
Active Noise Cancelling, IPX7 Waterproof, Touch Control for iPhone/Android - Black
```

**标题生成 Prompt：**

```text
请根据以下信息生成 5 个 Amazon 产品标题：

品牌：[品牌名]
产品：[产品名]
核心关键词：[关键词1], [关键词2]
核心卖点：[卖点1], [卖点2], [卖点3]
适用范围：[适用场景]
规格：[颜色/尺寸]

要求：
1. 每个标题不超过 200 字符
2. 核心关键词出现在前 60 字符
3. 不使用全大写（除品牌名和标准缩写）
4. 无促销用语（Best, #1, Free Shipping 等）
5. 5 个标题各有侧重，方便 A/B 测试
```

### 2.3 五点描述优化公式

每条 Bullet Point 用 **"USP（独特卖点）+ 支撑数据 + 使用场景"** 结构：

```text
请为以下产品生成 5 条五点描述：

产品：[产品名]
卖点列表：
1. [卖点1 - 如：40小时超长续航]
2. [卖点2 - 如：主动降噪35dB]
3. [卖点3 - 如：IPX7防水]
4. [卖点4 - 如：蓝牙5.3低延迟]
5. [卖点5 - 如：触控+语音助手]

每条格式：
【大写关键词短语】+ 具体数据支撑 + 使用场景/解决的痛点
长度：200-300 字符
自然融入关键词：[列出需要埋入的词]
```

## 三、转化率核心因素拆解

### 3.1 转化率影响因素权重

| 因素 | 影响权重 | 优化方向 |
|------|---------|---------|
| 主图质量 | 30% | 清晰、白底、展示核心卖点 |
| 价格竞争力 | 20% | 参考竞品定价，突出性价比 |
| 评论数量和质量 | 20% | 早期通过 Vine 计划积累 |
| 五点描述说服力 | 15% | 数据说话，解决痛点 |
| A+ 页面 | 10% | 品牌故事 + 使用场景 |
| 标题相关性 | 5% | 精准关键词引流 |

### 3.2 AI 提升转化率的实操方法

**A/B 测试标题转化率：**

```text
我有两个产品标题方案，请帮我分析哪个转化率可能更高，并给出理由：

方案 A：SoundMax Wireless Earbuds Bluetooth 5.3, Active Noise Cancelling
Headphones with 40H Battery, IPX7 Waterproof, Touch Control - Black

方案 B：SoundMax Bluetooth Earbuds, Wireless Noise Cancelling Earphones,
40 Hours Playtime, IPX7 Waterproof for Running/Gym, Built-in Mic

分析维度：
1. 关键词前置程度
2. 可读性
3. 信息完整度
4. 搜索覆盖面
5. 推荐方案及修改建议
```

**差评转化优化：**

```text
以下是我的产品最近 20 条差评，请帮我分析影响转化率的核心问题：

[粘贴差评内容]

请输出：
1. 差评分类（质量/物流/描述不符/其他）
2. 高频问题排名
3. 针对每个高频问题的 Listing 优化建议
4. 可以在五点描述中提前解决的期望偏差
5. 建议添加的 FAQ 条目
```

## 四、AI 辅助首图设计策略

### 4.1 主图设计规范

| 平台 | 白底要求 | 文字/水印 | 尺寸 |
|------|---------|----------|------|
| Amazon | 必须纯白 RGB(255,255,255) | 不允许 | ≥1000×1000px |
| 速卖通 | 纯白 | 允许少量 | 800×800px+ |
| TikTok Shop | 不强制 | 可以 | 1080×1080px+ |
| Shopify | 自由 | 自由 | 建议 2048×2048 |

```text

请规划 7 张副图的内容：
1. 图1-产品全家福

每张图给出：
- 构图描述
```

## 六、常见拒审原因与规避

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| Listing 被下架 | 违禁词/虚假宣传 | AI 扫描敏感词清单 |
| 图片被拒 | 非纯白底/尺寸不对 | 用 PhotoRoom 统一处理 |
| 变体违规 | 滥用变体合并评论 | 严格遵守变体政策 |
| 知识产权投诉 | 标题/图片侵权 | 上架前 AI 侵权检查 |
| 类目审核不通过 | 缺少认证文件 | 提前准备 FDA/CE 等 |

开店只是起点，Listing 优化是持续工程。建议每周花 30 分钟用 AI Review 一次搜索词报告，持续迭代关键词布局。
