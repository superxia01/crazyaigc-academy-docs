# 服务/教培/礼品/医美：营销视频、教案题库生成、公文写作、会议纪要

## AI 培训服务的市场机会

企业 AI 化的最大瓶颈不是技术，而是**人**。工具都在那里，但绝大多数从业者不会用、不敢用、用不好。AI 培训服务是一个快速增长的市场：

- 2025 年中国企业 AI 培训市场规模超 50 亿
- 70% 的企业计划在 1 年内开展 AI 培训
- 但合格的 AI 培训师严重不足

### 目标客户画像

| 客户类型 | 需求 | 付费意愿 | 复购可能 |
|----------|------|----------|----------|
| 大型企业 | 定制内训、全员覆盖 | 高（10万+/场） | 高（持续培训） |
| 中小企业 | 标准课程、实用导向 | 中（1-5万/场） | 中 |
| 创业者/个人 | 技能提升、变现方法 | 低（数百-数千） | 中 |
| 院校机构 | 课程体系、师资培训 | 中（3-10万） | 高（学期制） |
| 政府园区 | 企业赋能、政策培训 | 高（政府采购） | 中 |

## 培训课程设计

### 分层课程体系

| 层级 | 课程名 | 目标学员 | 时长 | 定价参考 |
|------|--------|----------|------|----------|
| L1 基础 | AI 通识与工具入门 | 全员 | 1天 | ¥800-2,000/人 |
| L2 进阶 | 岗位 AI 实操 | 业务骨干 | 2天 | ¥2,000-5,000/人 |
| L3 专项 | AI + 行业深度应用 | 部门负责人 | 2-3天 | ¥5,000-10,000/人 |
| L4 认证 | AI 应用师认证 | 企业内训师 | 5天 | ¥10,000-20,000/人 |

### 课程设计 Prompt

```
请帮我设计一门 [主题] 的 AI 培训课程：

培训对象：[描述学员背景]
培训目标：[学完能做什么]
培训时长：[X天/X小时]
学员现有水平：[零基础/有基础/精通]
行业背景：[行业]

请输出：
1. 课程大纲（分章节，每章含：主题、知识点、实操练习、时长）
2. 教学方法建议（讲授/演示/实操/讨论的占比）
3. 所需工具和素材清单
4. 课后作业/考核设计
5. 学员常见问题预判
```

## 教案题库生成

### AI 题库生成 Prompt

```
请根据以下课程内容，生成配套练习题库：

课程主题：[主题]
知识点范围：[列出关键知识点]
难度等级：[基础/中等/高级]
题目数量：[X道]

请按以下题型输出：
1. 单选题（10道，含答案和解析）
2. 多选题（5道）
3. 判断题（10道）
4. 场景实操题（3道，给出场景描述+评分标准）
5. 开放讨论题（2道）
```

### 教案生成 Prompt

```
请帮我生成一节 [X分钟] 的教案：

课程主题：[主题]
目标学员：[描述]
这节课的教学目标：
1. 知识目标：[学生要知道什么]
2. 技能目标：[学生能做什么]
3. 态度目标：[学生要理解什么]

请输出：
1. 导入环节（5分钟，用什么引入话题）
2. 知识讲解（含关键概念和案例）
3. 演示环节（现场操作步骤）
4. 练习环节（学员实操任务）
5. 总结回顾
6. 课后拓展资源
```

## 培训交付标准

### 培训前准备清单

- [ ] 确认学员名单和背景
- [ ] 发送课前调研问卷
- [ ] 准备课件（PPT+实操素材）
- [ ] 确认场地/线上平台
- [ ] 测试设备和网络
- [ ] 准备学员手册/资料包
- [ ] 建立学员群

### 培训后交付清单

- [ ] 发送课件和录屏
- [ ] 发放结业证书
- [ ] 收集满意度问卷
- [ ] 7 天后发送跟踪回访
- [ ] 30 天后发送效果评估
- [ ] 推荐进阶课程

### 满意度调查 Prompt

```
请帮我设计一份 AI 培训课程满意度调查问卷：

课程名称：[名称]
课程时长：[X天]

问卷需包含：
1. 整体满意度（1-5分）
2. 讲师评分（专业度/表达/互动）
3. 内容评分（实用性/难度/信息量）
4. 最有收获的部分
5. 希望改进的地方
6. 推荐意愿（NPS）
7. 后续培训需求
```

## 定价策略

### 成本核算公式

```
单人定价 = (讲师费 + 场地费 + 材料费 + 平台费 + 营销成本) ÷ 目标人数 × 利润率

参考：
- 讲师费：¥5,000-20,000/天
- 场地费：¥2,000-10,000/天
- 材料费：¥50-200/人
- 线上平台费：¥500-2,000/场
- 营销成本：定价的 20-30%
```
