# 硬件/制造：外观规避侵权微调、智能硬件渲染、工艺流程文档

## 硬件/制造行业 AI 赋能全景

制造业的核心诉求：**降本、增效、避坑（规避侵权和返工）**。AI 在硬件制造领域的应用不是替代工程师，而是加速 80% 的标准化工作。

### AI 赋能环节

| 环节 | AI 介入方式 | 效果 |
|------|------------|------|
| 外观设计 | AI 生成概念图+规避侵权 | 设计周期缩短 60% |
| 产品渲染 | AI 渲染替代传统建模渲染 | 成本降低 80% |
| 工艺文档 | AI 生成标准工艺流程文档 | 效率提升 5 倍 |
| 专利检索 | AI 辅助外观专利比对 | 规避侵权风险 |
| 供应链 | AI 分析供应商数据 | 采购成本优化 |
| 质量检测 | AI 视觉检测 | 检测效率 10 倍 |

## 外观设计规避侵权

### 侵权规避工作流

```
竞品外观采集 → AI 专利库检索 → 差异化设计 → 再检索确认 → 定稿
```

### 外观规避微调 Prompt

```
请根据以下产品外观描述，生成差异化设计方案：

原始产品：[描述外观特征]
竞品参考：[列出2-3个竞品的关键特征]
规避要点：[哪些元素必须避免]
保留功能：[哪些功能特征不可改变]
目标风格：[描述]

请输出3个差异化方案：
每个方案需说明：
1. 与竞品的关键差异点（至少3处）
2. 保留的功能性设计
3. 新增的视觉亮点
4. 外观专利通过的可能性评估
5. 消费者识别度分析
```

### 外观专利检索 Prompt

```
请帮我分析以下产品设计是否可能存在外观专利侵权风险：

我的设计描述：[详细描述]
已知竞品：[列出主要竞品]
品类：[电子产品/家电/家具/其他]

请输出：
1. 需要重点关注的竞品专利
2. 我的设计中可能与竞品相似的特征
3. 建议修改的差异化方向
4. 外观专利申请的可行性
```

## 智能硬件渲染

### 产品渲染 Prompt 工作流

**Step 1：基础渲染图**

```
Create a photorealistic product render:

Product: [产品描述，如"无线蓝牙音箱"]
Material: [材质：磨砂金属/塑料/玻璃/木质]
Color: [配色方案]
Style: Minimalist product photography
Background: [纯色/渐变/场景]
Lighting: Studio lighting, soft shadows
Resolution: 4K
Output: Front view + 45-degree angle + detail shot
```

**Step 2：场景渲染图**

```
Place the following product in a lifestyle scene:

Product: [描述]
Target user: [目标用户画像]
Usage scenario: [使用场景描述]
Time of day: [早晨/白天/傍晚/夜晚]
Mood: [温馨/科技/商务/户外]

请描述适合的场景构图和AI生成建议。
```

## 工艺流程文档

### AI 生成标准工艺流程 Prompt

```
请为以下产品生成标准工艺流程文档（SOP）：

产品名称：[名称]
产品类型：[电子产品/注塑件/钣金/其他]
生产工序：[列出已知工序]
质量标准：[描述]
产能要求：[X件/天]

请输出：
1. 工艺流程图（文字描述）
2. 每道工序的作业指导
3. 关键质量控制点
4. 所需设备和工装清单
5. 标准工时设定
6. 常见异常及处理方式
```

### BOM 表 AI 辅助

```
请根据以下产品描述，辅助生成 BOM（物料清单）：

产品：[名称和描述]
主要组件：[列出]
目标成本：[X元]
供应商偏好：[描述]

请输出：
1. 建议的 BOM 结构
2. 每个组件的材料建议
3. 预估成本区间
4. 替代方案（降成本版本）
5. 采购周期估算
```
