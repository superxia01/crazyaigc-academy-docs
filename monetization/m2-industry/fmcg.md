# 快消/餐饮：品牌宣发视频、菜单/海报视觉、活动文案/会员话术

## 快消行业 AI 赋能的核心场景

快消行业（FMCG）竞争白热化，产品同质化严重，**营销效率和产品创新速度**决定生死。AI 在快消领域的核心价值：

- **加速创意产出**：从月度到周级的营销素材迭代
- **降低试错成本**：AI 模拟测试替代部分市场调研
- **个性化触达**：基于 AI 的千人千面内容生成

### 快消 AI 应用全景

```
产品创新 → 包装设计 → 品牌营销 → 渠道运营 → 会员管理 → 数据洞察
   AI↑        AI↑        AI↑        AI↑        AI↑        AI↑
```

## 品牌宣发视频

### 快消品短视频矩阵

| 视频类型 | 用途 | 时长 | AI 辅助重点 |
|----------|------|------|------------|
| 品牌TVC | 品牌形象 | 15-60秒 | 分镜生成+特效 |
| 产品种草 | 电商详情页 | 15-30秒 | 脚本+批量出片 |
| KOL合作 | 社媒传播 | 30-60秒 | 脚本创意+效率 |
| 活动预告 | 促销引流 | 10-15秒 | 模板化批量生产 |
| 用户UGC | 口碑传播 | 10-30秒 | 二次创作工具 |

### 快消品视频脚本 Prompt

```
请为以下快消品生成短视频脚本：

品牌：[名称]
产品：[产品描述]
卖点：[1-3个核心卖点]
目标人群：[年龄/性别/场景]
视频类型：[种草/评测/故事/挑战]
时长：[15秒/30秒/60秒]
平台：[抖音/小红书/快手]

请输出：
1. 钩子（前3秒，必须抓住注意力）
2. 正文（卖点展示，场景化）
3. CTA（行动号召）
4. BGM风格建议
5. 画面分镜描述
6. 文案字幕
```

### 批量视频生产 SOP

```
周一：确定本周主题（结合促销节点）
周一：AI 批量生成5-10版脚本
周二-周三：拍摄/生成素材
周四：AI 辅助剪辑，批量输出
周五：审核+排期发布
```

## 菜单/海报视觉

### 餐饮菜单 AI 设计 Prompt

```
请为以下餐厅设计菜单视觉方案：

餐厅类型：[中餐/西餐/日料/咖啡厅]
风格定位：[高端/休闲/网红/家庭]
菜品数量：[X道]
特色菜：[3-5道需要突出]
价格区间：[人均X元]

请输出：
1. 菜单整体风格方向（3个方案）
2. 排版结构建议
3. 特色菜突出方式
4. 配色方案
5. 字体搭配
6. 拍摄/配图建议
```

### 活动海报 Prompt

```
请为以下快消品活动设计海报创意：

品牌：[名称]
活动类型：[促销/新品/节日/联名]
活动机制：[满减/买赠/抽奖/限时]
目标渠道：[线上/线下/全渠道]
视觉风格：[描述或参考]

请输出3版创意方向：
每版包含：
1. 主视觉构图
2. 标题文案
3. 信息层级排列
4. 配色方案
5. 适用场景（朋友圈/小红书/门店）
```

## 活动文案与会员话术

### 促销活动文案 Prompt

```
请为以下促销活动撰写全套文案：

品牌：[名称]
活动主题：[描述]
活动时间：[日期]
优惠内容：[具体机制]
目标渠道：[微信/短信/APP Push/社群]

请分别输出：
1. 朋友圈文案（3版，每版不同风格）
2. 短信文案（70字以内，2版）
3. APP Push文案（20字标题+50字正文）
4. 社群话术（引导互动+转化）
5. 公众号推文大纲
```

### 会员运营话术 Prompt

```
请为以下会员场景设计话术：

品牌：[名称]
会员等级：[新会员/活跃/沉睡/VIP]
目的：[激活/复购/升级/召回]
渠道：[企微/短信/APP/电话]

请输出：
1. 开场白（3种不同风格）
2. 核心话术（根据会员等级定制）
3. 异议应对（常见3种拒绝理由的处理）
4. 促单话术
5. 跟进话术（未成交后续跟进）
```
