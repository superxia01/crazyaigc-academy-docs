# 行政/国企：撰写公文、通知、汇报材料、整理会议纪要、优化办公流程

## 国企/政务 AI 应用的特殊背景

国企和政务机构有独特的 AI 应用需求：安全合规要求高、流程规范严格、汇报材料多、效率提升空间大。AI 在这个领域的核心价值不是"颠覆"，而是**降本增效 + 规范化**。

### 适用场景矩阵

| 场景 | AI 介入方式 | 效果预估 |
|------|------------|----------|
| 公文撰写 | AI 起草 + 人工审核 | 效率提升 5-10 倍 |
| 会议纪要 | 语音转写 + AI 摘要 | 节省 80% 整理时间 |
| 汇报材料 | AI 辅助数据可视化 | 提升专业度 |
| 政策解读 | AI 提取要点 + 对比 | 降低阅读门槛 |
| 流程优化 | AI 分析瓶颈 + 建议 | 缩短审批链 |
| 培训材料 | AI 批量生成课件 | 降低培训成本 |

## 公文撰写 AI 辅助

### 公文类型与 Prompt 模板

**通知类公文**

```
请根据以下信息撰写一份 [通知类型] 通知：

发文单位：[单位名称]
事由：[通知事由]
接收对象：[部门/人员]
具体内容：[要点描述]
时间要求：[截止时间]
联系人：[姓名及电话]

要求：
1. 格式符合公文规范
2. 语气正式、简洁
3. 包含标准公文要素（发文字号、签发人、主送、抄送等）
```

**汇报材料**

```
请帮我撰写一份 [月度/季度/年度] 工作汇报：

汇报人/部门：[名称]
汇报期间：[时间段]
核心工作：[列出3-5项重点]
数据指标：[关键数据]
下阶段计划：[要点]
存在的问题：[如实列出]

要求：
1. 结构清晰：成绩→问题→计划
2. 数据用表格呈现
3. 语言正式，避免口语化
4. 控制在 [X] 字以内
```

**会议纪要**

```
请根据以下会议录音转写文本，生成结构化会议纪要：

[粘贴转写文本]

会议纪要需包含：
1. 会议基本信息（时间、地点、参会人）
2. 议题列表
3. 每个议题的讨论要点
4. 会议决议
5. 待办事项（责任人 + 截止时间）
6. 下次会议安排
```

## 政务场景 AI 赋能

### 政策文件解读 Prompt

```
请对以下政策文件进行结构化解读：

[粘贴政策原文]

请输出：
1. 政策核心内容（3句话概括）
2. 与本部门相关的要点
3. 需要执行的具体事项
4. 时间节点和截止日期
5. 与前序政策的变化对比
6. 建议落实步骤
```

### 群众诉求分析 Prompt

```
请对以下群众诉求进行分类和分析：

[粘贴诉求内容]

请输出：
1. 诉求类型分类
2. 紧急程度评估
3. 对应责任部门
4. 建议回复要点
5. 历史相似案例提示
```

## 国企数字化转型案例框架

### 案例：某央企集团 AI 赋能办公效率

| 维度 | 改造前 | 改造后 | 提升 |
|------|--------|--------|------|
| 公文撰写 | 2-3天/份 | 半天/份 | 70% |

| 周报汇总 | 各部门半天 | AI 自动汇总 | 80% |

### 实施步骤

```
第一步：选择低风险场景试点
  → 公文模板、会议纪要、周报汇总

第二步：建立安全使用规范
  → 内网部署或私有化方案
  → 数据分级，敏感数据不上云

第三步：分层培训
  → 领导层：认知提升（1次讲座）
  → 骨干层：工具实操（2天培训）
  → 全员：基础使用（在线课程）

第四步：扩展应用
  → 从办公延伸到业务（合同审查、报告生成）

第五步：效果评估与优化
  → 量化指标跟踪
  → 每季度复盘
```

## 数据安全与合规要点

### 数据分级标准

| 级别 | 数据类型 | AI 处理方式 |
|------|----------|------------|
| 公开 | 对外公告、新闻稿 | 可用云端 AI |
| 内部 | 内部通知、培训材料 | 企业版 AI/私有化 |
| 敏感 | 人事、财务数据 | 私有化部署 |
| 机密 | 战略规划、涉密文件 | 不使用外部 AI |

### AI 使用合规检查清单

- [ ] 使用的 AI 工具是否通过安全评估
- [ ] 数据传输是否加密
- [ ] AI 服务商是否签署保密协议
- [ ] 是否建立 AI 输出审核机制
- [ ] 是否有 AI 使用日志记录
- [ ] 是否定期进行安全审计
