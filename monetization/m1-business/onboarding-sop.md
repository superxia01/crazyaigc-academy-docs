# 接单 SOP：建立高效接单工作流与个人素材库

## 为什么需要标准化入驻流程

新客户入驻是你和客户建立信任的第一步。一个专业的入驻流程能：
- 降低沟通成本 60% 以上
- 减少后期返工和纠纷
- 让客户感受到"这是个靠谱的服务商"
- 提高项目启动速度

没有标准流程的后果：反复问同样的问题、漏掉关键信息、项目开始后才发现预算不匹配。

## 入驻 SOP 全流程

```
初次接触 → 资格预审 → 需求深挖 → 方案报价 → 签约 → 项目启动 → 交付标准对齐
```

## 第一步：初次接触（30分钟内响应）

### 标准话术模板

```
您好！感谢您联系 [工作室名称]。

为了更高效地为您服务，请您花 2 分钟填写以下信息：
1. 您的公司/品牌名称？
2. 项目类型（视觉/视频/文案/其他）？
3. 大概的交付物和数量？
4. 期望完成时间？
5. 预算范围？

收到信息后，我们会在 [X] 小时内给您初步方案和报价。
```

### 客户分级标准

| 等级 | 特征 | 服务策略 |
|------|------|----------|
| A级 | 预算充足、需求清晰、长期合作潜力 | 优先响应，可提供定制方案 |
| B级 | 预算适中、需求基本清晰 | 标准流程，套餐服务 |
| C级 | 预算较低、需求模糊 | 引导至标准化产品/模板 |

## 第二步：需求深挖（1-2天）

### 客户信息采集表

| 类别 | 采集内容 | 工具 |
|------|----------|------|
| 基本信息 | 公司名称、行业、联系人 | 表单/问卷 |
| 品牌资料 | Logo、VI手册、品牌调性 | 网盘链接 |
| 项目需求 | 类型、数量、用途、投放渠道 | 需求表 |
| 参考资料 | 竞品链接、参考风格图 | 截图/链接 |
| 技术要求 | 尺寸、格式、分辨率 | 规格表 |
| 时间预算 | Deadline、预算范围 | 直接沟通 |

### AI 辅助客户画像分析 Prompt

```
根据以下客户信息，帮我分析这个客户的需求特征和服务策略：

客户行业：[行业]
公司规模：[规模]
项目类型：[类型]
预算范围：[X-Y万]
历史合作：[有/无]
沟通风格：[描述]

请输出：
1. 客户需求优先级排序
2. 潜在需求挖掘建议
3. 推荐服务方案（基础/标准/高级）
4. 沟通注意事项
5. 预估项目风险点
```

## 第三步：方案报价（当天出稿）

### 三档报价策略

| 套餐 | 内容 | 适用客户 | 定价建议 |
|------|------|----------|----------|
| 基础版 | 满足基本需求，2轮修改 | C级客户 | 市场价 70% |
| 标准版 | 完整交付+3轮修改+售后 | B级客户 | 市场价 100% |
| 高级版 | 全套+长期维护+素材库搭建 | A级客户 | 市场价 150% |

### AI 辅助方案定制 Prompt

```
根据客户需求，帮我定制三档服务方案：

客户核心需求：[描述]
行业特点：[描述]
预算范围：[范围]

请输出三档方案对比表，每档包含：
1. 服务内容清单
2. 交付物数量及规格
3. 修改次数
4. 交付周期
5. 建议报价
6. 与其他档位的差异化卖点
```

## 第四步：签约与启动

### 签约清单

- [ ] 合同签署（电子签/纸质）
- [ ] 预付款到账确认
- [ ] 品牌资料接收确认
- [ ] 项目群/沟通渠道建立
- [ ] 项目排期确认
- [ ] 对接人确认（双方各一人）

### 项目启动会（15-30分钟）

1. 项目背景和目标对齐
2. 确认交付物清单和验收标准
3. 确认沟通频率和方式
4. 确认关键时间节点
5. 答疑

## 第五步：交付标准对齐

### 交付标准模板

```
项目：[名称]
交付标准：

1. 视觉类
   - 分辨率：≥300dpi（印刷）/ ≥72dpi（数字）
   - 色彩模式：CMYK（印刷）/ RGB（数字）
   - 格式：源文件 + 导出文件

2. 视频类
   - 分辨率：1080p / 4K
   - 时长：±5%
   - 格式：MP4 (H.264)
   - 字幕：内嵌/外挂

3. 文案类
   - 字数范围
   - 风格调性
   - 是否含 SEO 关键词
```

## 客户档案管理

### 每个客户一个档案夹

```
客户名_行业/
├── 01_基本信息/
│   ├── 客户信息表.md
│   └── 品牌资料/
├── 02_项目/
│   ├── 项目A/
│   └── 项目B/
├── 03_合同/
└── 04_沟通记录/
```

### AI 辅助客户跟进 Prompt

```
根据以下客户沟通记录，帮我生成跟进计划：

首次沟通日期：[日期]
客户需求：[描述]
当前状态：[报价中/等待确认/已签约]
下次跟进时间：[日期]

请输出：
1. 跟进要点
2. 推荐沟通话术
3. 需要准备的资料
4. 异议应对预案
```

## 常见入驻问题处理

| 问题 | 处理方案 |
|------|----------|
| 预算远低于合理价 | 推荐简化版方案或模板服务 |
| 需求描述极其模糊 | 用选择题引导，不给开放式问题 |
| 要免费试稿 | 可提供过往案例，或做低价试单 |
| 催稿/加急 | 明确加急费用（通常加收 30-50%） |
| 要独家版权 | 正常报价 + 版权买断费（1-3倍） |

## 入驻 SOP 时间节点

| 步骤 | 时间 | 产出 |
|------|------|------|
| 初次响应 | 30分钟内 | 标准回复 |
| 需求深挖 | 1-2天 | 需求文档 |
| 方案报价 | 1天 | 三档方案 |
| 签约启动 | 1-3天 | 合同+排期 |
| 标准对齐 | 签约当天 | 验收标准文档 |
