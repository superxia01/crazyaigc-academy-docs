# 全流程跑通：个人/微型团队如何实现导演+美术+后期闭环

## 全流程闭环的核心理念

个人或微型团队接商单，最大的挑战不是技术，而是**流程管理**。AI 工具让一个人可以完成以前需要一个团队的工作，但前提是你有清晰的 SOP。没有 SOP，你会陷入：

- 反复修改，不知道哪一版是终版
- 客户说"这不是我要的"，但你以为理解了需求
- 交付时缺东少西，临时赶工

## 全流程 SOP 总览

```
需求沟通 → 方案确认 → 预付款 → 执行生产 → 内审 → 初稿交付 → 客户反馈 → 修改 → 终稿验收 → 尾款 → 归档复盘
```

## 第一阶段：需求沟通（Day 1）

### 需求确认表

| 信息项 | 必须确认 | 获取方式 |
|--------|----------|----------|
| 项目类型 | ✅ | 客户描述 |
| 目标受众 | ✅ | 直接询问 |
| 风格参考 | ✅ | 索要参考图/竞品链接 |
| 交付物清单 | ✅ | 逐项确认 |
| 交付格式 | ✅ | 明确规格 |
| 使用场景 | ✅ | 了解投放渠道 |
| 预算范围 | ✅ | 提前试探 |
| 时间节点 | ✅ | 反向排期 |
| 品牌规范 | 如有 | 索要 VI 手册 |

### AI 辅助需求整理 Prompt

```
你是一位资深项目经理。请根据以下客户原始需求，整理出一份结构化的需求文档：

客户原话：[粘贴客户描述]

请输出：
1. 核心需求（一句话概括）
2. 交付物清单（具体到格式和数量）
3. 技术要求（分辨率、色彩模式、时长等）
4. 需要向客户确认的疑问点
5. 潜在风险提示
```

## 第二阶段：方案确认与签约（Day 1-2）

### 方案书要点
1. **创意方向**：文字描述 + 2-3 张情绪板（Moodboard）
2. **交付物清单**：逐项列明，附规格
3. **时间排期**：倒推法，从 deadline 往前排
4. **报价明细**：拆项报价，让客户感知价值

### AI 辅助方案生成 Prompt

```
根据以下需求信息，帮我生成一份项目方案书：

[需求文档]

方案书需包含：
1. 项目理解（展示你懂客户的需求）
2. 创意方向建议（2-3 个方向）
3. 分阶段排期表
4. 交付物清单及规格
5. 报价明细
```

## 第三阶段：执行生产（Day 3-N）

### 生产流程标准化

| 交付物类型 | 工具链 | 关键节点 |
|-----------|--------|----------|
| 品牌视觉 | Midjourney → PS 精修 | 3稿选1 |
| 产品图 | AI 生成 → 局部替换 → 调色 | 白底+场景各一套 |
| 短视频 | 脚本AI → 分镜 → 剪辑 | 先确认脚本再拍摄/生成 |
| 文案 | ChatGPT 起草 → 人工润色 | 先大纲再正文 |

### 内审 Checklist

- [ ] 是否符合品牌调性
- [ ] 文字是否有错别字/敏感词
- [ ] 图像是否有 AI 瑕疵（多余手指、水印等）
- [ ] 尺寸/格式是否符合交付要求
- [ ] 与方案书承诺是否一致

## 第四阶段：交付与验收

### 交付包标准结构

```
项目名称_交付包/
├── 01_终稿/
│   ├── 文件1.psd
│   ├── 文件1.png
│   └── 文件2.mp4
├── 02_过程稿/（可选）
│   └── 初稿/
├── 03_素材源文件/
│   └── AI生成原图/
└── 04_说明文档.pdf
```

### AI 辅助交付说明 Prompt

```
请帮我撰写一份项目交付说明，包含：

项目名称：[XXX]
交付物：[列出具体文件]
修改记录：[列出每次修改的内容]

需包含：
1. 交付物清单及说明
2. 文件使用建议
3. 如需二次修改的联系方式
4. 感谢语
```

## 第五阶段：归档与复盘

### 复盘四问

| 问题 | 目的 |
|------|------|
| 实际工时 vs 预估工时 | 优化报价准确性 |
| 修改次数及原因 | 优化需求沟通流程 |
| 客户满意度反馈 | 建立口碑 |
| 可复用的素材/模板 | 积累个人素材库 |

### AI 辅助复盘 Prompt

```
请帮我分析这个项目的复盘数据：

项目：[名称]
预估工时：[X]小时，实际：[Y]小时
报价：¥[X]，修改次数：[N]次
主要修改原因：[列出]

请分析：
1. 工时偏差原因
2. 报价是否合理（实际时薪）
3. 哪些环节可以优化
4. 给出下次同类项目的建议报价
```

## 时间管理建议

| 团队规模 | 建议并行项目数 | 单项目周期 |
|----------|---------------|-----------|
| 1人 | 2-3个（错峰） | 5-10天 |
| 2-3人 | 4-6个 | 3-7天 |
| 4-5人 | 8-10个 | 3-5天 |

## 关键原则

1. **先收钱再干活**：至少 40% 预付
2. **书面确认每一步**：方案、初稿、终稿都要书面确认
3. **管好客户预期**：宁可前期多说难点，不要过度承诺
4. **建立个人素材库**：每个项目的可复用素材分类存档
5. **持续优化 SOP**：每完成一个项目，更新你的流程模板

## 行动清单

- [ ] 建立项目文件夹模板（按阶段分目录）
- [ ] 制作需求确认表（首次沟通必填）
- [ ] 搭建个人素材库（按风格/行业/类型分类）
- [ ] 记录每个项目的工时和修改次数
- [ ] 每月做一次复盘，优化报价和流程
