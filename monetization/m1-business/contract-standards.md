# 合同规范：AI 视觉与视频商业项目的合同规范与积分制/项目制逻辑

## 为什么需要标准化合同

AI 辅助生成服务与传统外包有本质区别：交付物是数字资产，存在版权归属、修改迭代、质量标准等特殊问题。一份模糊的口头约定，可能导致：
- 无限修改循环，利润被吞噬
- 版权纠纷，甲方声称拥有所有 AI 生成素材的独家权利
- 交付标准不清，验收时扯皮

## 核心合同条款清单

| 条款 | 必要性 | 关键要点 |
|------|--------|----------|
| 服务范围 | ⭐⭐⭐ | 明确交付物类型、数量、格式、分辨率 |
| 修改次数 | ⭐⭐⭐ | 限定免费修改轮数（建议 2-3 轮），超出另行计费 |
| 交付时间 | ⭐⭐⭐ | 分阶段交付节点，每阶段验收标准 |
| 版权归属 | ⭐⭐⭐ | 区分最终交付物版权 vs AI 原始生成物的使用权 |
| 付款方式 | ⭐⭐⭐ | 预付比例（建议 40-50%）、尾款条件 |
| 违约责任 | ⭐⭐ | 延期交付、质量不达标的处理方式 |
| 保密条款 | ⭐⭐ | 甲方品牌信息、未发布产品的保密义务 |

## AI 生成服务合同模板（精简版）

```
甲方：[公司名称]
乙方：[服务商名称]

一、服务内容
乙方为甲方提供以下 AI 辅助生成服务：
- 项目名称：______
- 交付物清单：______（详见附件一：项目范围书）
- 交付格式：______
- 交付数量：______

二、项目周期
- 初稿交付：签约后 ____ 个工作日
- 修改周期：每轮修改 ____ 个工作日
- 终稿交付：验收通过后 ____ 个工作日内

三、费用与付款
- 项目总费用：¥______（含税）
- 付款方式：预付 __% + 尾款 __%
- 尾款支付条件：终稿验收通过后 __ 个工作日内

四、修改条款
- 免费修改次数：__ 轮（每轮不超过 __ 项修改意见）
- 超出部分按单项计费：¥____/项

五、版权说明
- 最终交付物版权归甲方所有
- 乙方保留作品集展示权（商业敏感内容可协商排除）
- AI 生成过程中的中间素材归属按附件约定执行

六、保密条款
双方对项目涉及的商业信息负有保密义务，保密期 ____ 年。

甲方签章：                乙方签章：
日期：                    日期：
```

## 积分制 vs 项目制对比

| 维度 | 积分制 | 项目制 |
|------|--------|--------|
| 适用场景 | 长期合作、多类型需求 | 单次/周期性大项目 |
| 计价方式 | 预存积分，按任务消耗 | 固定总价或按阶段 |
| 灵活性 | 高，随用随扣 | 中，需变更流程 |
| 客户粘性 | 高（预付费） | 中 |
| 风险 | 积分贬值争议 | 范围蔓延 |
| 推荐定价 | 1积分≈1元，1000积分起充 | 按项目复杂度报价 |

```
4. 是否缺少关键保护性条款
5. 是否存在模糊表述可能导致争议

[粘贴合同文本]

```

## 常见坑与应对

| 坑 | 后果 | 应对 |
|----|------|------|
| "满意为止" | 无限修改 | 合同写明修改轮数 |
| 版权全部归甲方 | 无法做案例展示 | 保留展示权 |
| 无预付款 | 尾款难收 | 至少 40% 预付 |
| 口头变更 | 范围失控 | 所有变更书面确认 |
| 未约定AI生成物归属 | 法律灰色地带 | 合同明确约定 |
