# 需求沟通：接洽商单技巧、将模糊需求转化为精准指令

## 需求沟通的黄金法则

**客户说的不是需求，是愿望。** 你的工作是把愿望翻译成可执行的需求。

90% 的项目返工不是因为能力不够，而是需求没搞清楚。AI 工具可以快速出稿，但如果方向错了，速度只会让你更快地犯错。

## 需求沟通三阶段

```
阶段一：听（收集原始需求）→ 阶段二：问（深挖真实需求）→ 阶段三：确认（锁定执行需求）
```

## 阶段一：收集原始需求

### 客户常说 vs 实际需求

| 客户原话 | 真实需求 | 你应该问的 |
|----------|----------|-----------|
| "要高端大气" | 品牌升级/高端定位 | "能发3张您觉得高端的参考图吗？" |
| "随便做做就行" | 预算有限但不想降低标准 | "预算大概在什么范围？" |
| "参考一下XX品牌" | 想要类似风格 | "喜欢它的哪个方面？配色？排版？调性？" |
| "明天就要" | 内部催得急 | "最晚什么时候必须用上？有几个节点？" |
| "说不清楚，你先做一版" | 需求还没想清楚 | "我提供3个方向，您选一个，这样效率更高" |

### 首次沟通 Checklist

- [ ] 项目类型和用途
- [ ] 目标受众
- [ ] 风格偏好（索取参考）
- [ ] 交付物清单和规格
- [ ] 时间节点
- [ ] 预算范围
- [ ] 决策流程（谁拍板）

## 阶段二：深挖真实需求

### 5W2H 需求分析法

| 维度 | 问题 | 目的 |
|------|------|------|
| What | 做什么？具体交付物？ | 明确范围 |
| Why | 为什么做？解决什么问题？ | 理解目标 |
| Who | 给谁看？决策人是谁？ | 锁定受众和流程 |
| Where | 在哪里投放/使用？ | 确定规格 |
| When | 什么时候要？关键节点？ | 排期 |
| How | 怎么衡量成功？ | 验收标准 |
| How much | 预算多少？ | 定价依据 |

### AI 辅助需求分析 Prompt

```
你是一位资深客户经理。请根据以下客户的原始描述，进行需求分析：

客户原话："[粘贴客户沟通记录]"

请输出：
1. 表面需求（客户直接说的）
2. 深层需求（客户没说但实际需要的）
3. 需要进一步确认的问题清单（不超过5个）
4. 潜在需求/追加需求的可能性
5. 需求风险评估（模糊点、矛盾点）
```

## 阶段三：确认锁定需求

### 需求确认书模板

```
【需求确认书】

项目名称：______
确认日期：______

一、项目目标
[一句话描述]

二、交付物清单
| 序号 | 交付物 | 规格 | 数量 | 备注 |
|------|--------|------|------|------|

三、风格方向
[附参考图/情绪板链接]

四、时间节点
| 节点 | 日期 | 交付内容 |
|------|------|----------|

五、验收标准
[量化标准]

六、本次不包含
[明确排除项，防止范围蔓延]

客户确认签字：______
我方确认签字：______
```

> ⚠️ 需求确认书必须双方书面确认（微信/邮件截图均可），不要只靠口头约定。

## AI 辅助方案撰写

### 方案书结构 Prompt

```
请根据以下已确认的需求信息，帮我撰写项目方案书：

需求概要：[从需求确认书摘录]
客户行业：[行业]
品牌调性：[描述]

方案书需包含：
1. 项目理解（向客户展示我们懂了）
2. 创意方向（2-3个方向，每个方向一句话描述+参考图建议）
3. 执行计划（分阶段、有时间节点）
4. 交付物清单（与需求确认书对应）
5. 报价明细
6. 服务保障（售后、修改条款）
```

### 客户提案沟通 Prompt

```
请帮我准备一份向客户提案的沟通要点：

方案亮点：[列出2-3个核心卖点]
客户可能的疑虑：[预判]
竞品方案可能的差异：[分析]

请输出：
1. 开场白（30秒说清核心价值）
2. 方案讲解逻辑（先说结论，再说细节）
3. 疑虑应对话术
4. 促单话术（引导客户做决定）
```

## 处理模糊需求的实操技巧

### "我要好看"类需求

```
应对流程：
1. 不直接问"什么是好看"（客户说不清）
2. 主动提供选择题：
   "这里有3个方向：
   A. 简约现代风（参考：Apple）
   B. 活力年轻风（参考：喜茶）
   C. 高端商务风（参考：华为）
   您更倾向哪个方向？"
3. 客户选后，再在该方向内细化
```

### "我也不知道要什么"类需求

```
应对流程：
1. 先了解业务背景："这个物料是给谁看的？想达成什么效果？"
2. 从业务目标反推设计方向
3. 出3个差异化方向的小样（quick draft）
4. 让客户选方向，再深耕
```

### 需求频繁变更的客户

```
应对策略：
1. 每次变更都书面确认，记录版本号
2. 变更超过3次，触发"范围变更流程"——重新评估工期和报价
3. 话术："理解您的新想法。这个变更会影响[工期/报价]，
   我更新一下方案，您确认后我们继续推进。"
```

## AI 辅助客户沟通 Prompt 合集

### 拒绝不合理需求

```
请帮我委婉但坚定地回复客户以下不合理需求：

客户要求：[描述]
合同约定：[原约定内容]

要求：
1. 先肯定客户的想法
2. 说明为什么无法在当前范围内满足
3. 给出替代方案或追加报价
4. 语气专业、不卑不亢
```

### 催确认/催付款

```
请帮我写一封催促客户确认方案/付款的礼貌信息：

项目：[名称]
等待事项：[方案确认/付款]
等待天数：[X天]
上次沟通：[日期]

要求：
1. 不显得催促
2. 强调为了保障项目进度
3. 给出具体时间建议
```
