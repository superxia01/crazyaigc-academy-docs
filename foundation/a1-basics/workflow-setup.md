# 个人/团队 AI 工作流搭建：从需求提出到 AI 输出的完整实操

## 什么是 AI 工作流？

AI 工作流就是把"用 AI 完成任务"这件事变成一个 **可重复、标准化的流程**。

```
没有工作流：每次用 AI 都从头开始，效果时好时坏
有了工作流：固定步骤、固定模板，质量和效率都稳定
```

### 工作流的三个层次

| 层次 | 说明 | 举例 |
|------|------|------|
| 单步工作流 | 一个 Prompt 解决一个问题 | "帮我润色这段文字" |
| 多步工作流 | 多个 Prompt 串联完成复杂任务 | 写文章：大纲→初稿→润色→排版 |
| 自动化工作流 | 工具串联，减少人工干预 | 定时采集数据→AI 分析→自动发报告 |

## 实战一：搭建个人 AI 工作流

### Step 1：梳理你的日常工作

用以下模板列出你每天/每周的重复任务：

| 任务 | 频率 | 耗时 | AI 能帮忙吗 | 优先级 |
|------|------|------|-------------|--------|
| 写周报 | 每周 | 30 分钟 | ✅ 生成初稿 | 高 |
| 回复客户消息 | 每天 | 1 小时 | ✅ 生成回复 | 高 |
| 整理会议纪要 | 每周 2 次 | 20 分钟 | ✅ AI 整理 | 中 |
| 数据报表 | 每月 | 2 小时 | ✅ AI 分析 | 中 |
| 社媒内容 | 每天 | 1 小时 | ✅ AI 生成 | 高 |

### Step 2：为每个任务设计 Prompt 模板

**周报生成 Prompt：**

```
你是一个周报助手。请根据以下信息生成本周工作周报：

本周完成事项：
{在这里列出你完成的工作，每行一条}

进行中的事项：
{列出现状}

下周计划：
{列出计划}

输出格式：
## 本周工作总结
（按项目/模块分组，每项包含：做了什么、结果是什么）

## 进行中的工作
（当前状态和阻塞点）

## 下周计划
（具体可执行的事项）

## 需要的支持
（如需协调资源请列出）
```

**客户回复 Prompt：**

```
请帮我回复以下客户消息，要求：
1. 语气专业友好
2. 先共情再解决问题
3. 如果需要更多信息，礼貌地询问
4. 回复长度控制在 100 字以内

客户消息：{粘贴客户消息}
背景信息：{补充相关上下文}
```

### Step 3：把 Prompt 模板存好

推荐存储方式：

| 方式 | 工具 | 适合场景 |
|------|------|----------|
| 文档 | 飞书文档/Notion | 团队共享 |
| 本地文件 | Obsidian/Markdown 文件 | 个人使用 |
| 快捷指令 | 键盘快捷键/Text Expander | 高频使用 |
| AI 记忆 | 在对话中让 AI "记住这个模板" | 单次会话内 |

## 实战二：搭建团队 AI 工作流

### 团队工作流设计原则

```
原则 1：统一工具 —— 全团队用同一个 AI 平台，Prompt 可复用
原则 2：模板先行 —— 常见场景都有标准化 Prompt 模板
原则 3：人工审核 —— AI 输出必须有人检查后才发出
原则 4：持续迭代 —— 每周回顾 AI 输出质量，优化模板
```

### 团队 Prompt 模板库示例

**市场部——公众号文章：**

```
你是一个公众号写手。请根据以下主题写一篇公众号文章：

主题：{主题}
目标读者：{读者画像}
字数：{字数}
风格：{专业/轻松/干货}

文章结构：
1. 标题（给 3 个备选）
2. 开头：用痛点或故事引入
3. 正文：分 3-5 个小节，每节有小标题
4. 结尾：总结 + 行动号召

要求：
- 段落简短，适合手机阅读
- 适当使用 emoji
- 每 300 字左右插入一个图片占位标记 [配图：描述]
```

**销售部——客户方案：**

```
请根据以下信息生成一份客户解决方案：

客户行业：{行业}
客户规模：{人数/营收}
客户痛点：{痛点描述}
我们的产品：{产品名和核心功能}

方案结构：
1. 客户现状分析
2. 痛点诊断
3. 解决方案（对应每个痛点给出方案）
4. 实施计划（分阶段）
5. 预期效果（量化指标）
6. 投资回报分析

语气：专业、自信、务实
```

### 团队工具链搭建

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│ 需求输入  │ → │ AI 生成   │ → │ 人工审核  │ → │ 发布/执行 │
│ (飞书表单) │   │ (模板+AI) │   │ (负责人)  │   │ (对应渠道)│
└──────────┘   └──────────┘   └──────────┘   └──────────┘
```

具体工具链：

| 环节 | 推荐工具 | 说明 |
|------|----------|------|
| 需求提交 | 飞书多维表格 | 表单收集需求 |
| AI 处理 | Kimi/ChatGPT | 按模板生成内容 |
| 协作审核 | 飞书文档 | 多人批注修改 |
| 发布分发 | 对应平台 | 公众号/邮件/社媒 |
| 效果追踪 | 飞书仪表盘 | 数据看板 |

## 实战三：自动化工作流搭建

### 场景：每日竞品监控自动化

```
工作流设计：
1. 每天 9:00 定时执行
2. 爬取竞品网站/社媒更新
3. AI 总结关键变化
4. 发送到飞书群

实现步骤：
Step 1：用 Python 脚本采集竞品信息（AI 生成爬虫代码）
Step 2：用 AI 总结分析采集到的数据
Step 3：通过飞书 Webhook 发送消息
Step 4：配置 crontab 或云函数定时触发
```

### Prompt：生成自动化脚本

```
请帮我写一个每日竞品监控脚本：

监控目标：
- 竞品 A 官网新闻页
- 竞品 B 公众号（提供 RSS 或其他获取方式）

每日任务：
1. 检查是否有新文章/公告
2. 如果有，提取标题、摘要、发布时间
3. 用 AI 总结核心变化（价格调整、新产品、促销活动等）
4. 格式化为飞书卡片消息
5. 通过 Webhook 发送到指定群

要求：
- 记录已处理的文章 URL，避免重复推送
- 出错时发送错误通知
- 支持配置文件管理竞品列表和 Webhook 地址
```

## 工作流搭建的 4 个阶段

```
阶段 1（第1周）：列出任务 → 手动用 AI 完成 → 记录有效 Prompt
阶段 2（第2周）：整理 Prompt 模板 → 建立个人模板库
阶段 3（第3-4周）：团队共享模板 → 统一工具和流程
阶段 4（持续）：识别自动化机会 → 脚本/工具串联
```

## 常见问题

**Q：工作流搭建好了，但团队不愿意用怎么办？**
从一个最痛的场景切入（如周报），让大家先体验到效率提升，再逐步推广。

**Q：AI 输出质量不稳定？**
固定 Prompt 模板 + 给 AI 提供充足的上下文信息 + 人工审核兜底。质量 = Prompt 质量 × 上下文质量。

**Q：工作流需要经常调整吗？**
核心流程稳定后，主要是 Prompt 微调。建议每月 review 一次模板，根据使用反馈优化。
