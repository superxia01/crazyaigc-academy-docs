# 精准指令句式：角色 + 任务 + 要求 + 输出格式的万能公式

有没有一个万能公式，让 AI 每次都能给出你想要的答案？有。就是这四个模块：

**角色 + 任务 + 要求 + 输出格式**

这四个模块就像搭积木，全部用上就是精准指令，少一个就容易翻车。

## 万能公式拆解

```
【角色】你是一位 [具体角色，而非笼统描述]
【任务】请帮我完成 [具体可执行的任务]
【要求】需要满足 [约束条件、质量标准、注意事项]
【输出格式】请按 [指定格式] 输出
```

### 为什么是这四个？

| 模块 | 作用 | 不加会怎样 |
|------|------|-----------|
| 角色 | 锚定 AI 的知识范围和语言风格 | 回答大而全，没有针对性 |
| 任务 | 明确要做什么 | AI 不知道该输出什么 |
| 要求 | 划定边界和质量标准 | 输出可能偏离你的预期 |
| 输出格式 | 控制结果的形式 | 返回一大段文字，不方便使用 |

## 逐步拆解每个模块

### 模块一：角色——越具体越好

**差的写法：**
```
你是一个营销专家
```

**好的写法：**
```
你是一位服务过 20+ 消费品牌的独立营销顾问，擅长为月营收 100-500 万
的电商品牌制定增长策略，沟通风格直接，不废话。
```

**角色设定的三个层次：**

| 层次 | 示例 | 效果 |
|------|------|------|
| 笼统 | "你是一位营销专家" | 输出通用、模板化 |
| 细化 | "你是一位电商营销顾问" | 更贴合场景 |
| 具象 | "你是服务过三顿半、完美日记等品牌的增长顾问" | 输出有实战感和行业洞察 |

**技巧：** 如果你是某个行业的，在角色里加上行业关键词；如果你想要某种风格，在角色里描述这个人"怎么说话"。

### 模块二：任务——动词开头，一事一令

**差的写法：**
```
帮我看看这个方案怎么样，顺便改一改，如果可以的话再写个新版本
```
（三个任务混在一起，AI 不知道重点是什么）

**好的写法：**
```
请评估以下营销方案，指出 3 个最大的问题和 3 个亮点。
```
（一个明确的动作，有具体的数量要求）

**常用任务动词：**

| 类型 | 动词 |
|------|------|
| 创作类 | 写、生成、创作、设计、起草 |
| 分析类 | 分析、评估、诊断、拆解、对比 |
| 修改类 | 优化、改写、精简、扩写、润色 |
| 整理类 | 总结、归纳、提取、分类、排序 |
| 策划类 | 规划、制定、设计、安排、编排 |

### 模块三：要求——说清楚"不要什么"

很多人的提示词只说"要什么"，不说"不要什么"。结果 AI 按自己的理解发挥，偏离预期。

**差的写法：**
```
写一篇文章，要好一点的
```

**好的写法：**
```
要求：
- 字数 800-1200 字
- 面向非技术读者，不要出现专业术语
- 每段不超过 4 句话
- 不要用"首先其次最后"这种模板化过渡
- 不要在结尾写"让我们一起"之类的口号
```

**要求可以从这些维度写：**

| 维度 | 示例 |
|------|------|
| 长度 | "300 字以内"/"至少 5 个要点" |
| 受众 | "说给初中生听"/"给 CEO 汇报用" |
| 调性 | "正式商务"/"朋友聊天"/"不卑不亢" |
| 禁忌 | "不要用 AI 味的总结"/"不要自我夸耀" |
| 质量 | "必须有具体数据支撑"/"每个观点都要有案例" |

### 模块四：输出格式——减少二次加工

明确格式可以省去你整理的时间。

**常用格式指定：**

| 场景 | 格式指令 |
|------|---------|
| 要点汇总 | "请用要点列表输出，每条不超过 20 字" |
| 对比分析 | "请用表格对比，列包括：[列名]" |
| 方案文档 | "请按以下结构输出：一、背景 / 二、分析 / 三、方案 / 四、计划" |
| 数据记录 | "请用 JSON 格式输出，字段包括：name, type, description" |
| 执行清单 | "请用 Todo 清单格式，每项标注优先级（高/中/低）和预计时间" |

## 完整公式实战示例

### 示例 1：写一份产品介绍

```
你是一位有 8 年经验的 SaaS 产品文案策划。（角色）

请为我们的在线协作工具"飞书"写一版面向中小企业老板的产品介绍，
重点突出"帮团队少开会、多干活"。（任务）

要求：
- 篇幅 400-600 字
- 用 3 个具体使用场景替代抽象功能描述
- 语言朴素，不用"赋能""助力"这类词
- 读完后让人想试用，而不是觉得在看广告（要求）

输出格式：
标题（1 句）
副标题（1 句）
正文（3 个场景 + 1 个行动引导）
（输出格式）
```

### 示例 2：分析竞品

```
你是一位互联网行业分析师，长期跟踪 SaaS 和协同办公赛道。（角色）

请对比分析"飞书"和"钉钉"两款产品在中小企业市场的竞争力差异。（任务）

要求：
- 从产品功能、定价策略、生态开放度、用户口碑 4 个维度分析
- 每个维度必须引用至少 1 个具体事实（功能名称/价格/数据）
- 最后给出"如果我是 50 人团队负责人，选哪个"的明确建议
- 不要端水，给出倾向性结论（要求）

输出格式：
总览表格（4 个维度 × 2 个产品）
详细分析（每个维度 100 字左右）
最终建议（200 字以内，含选择理由）（输出格式）
```

### 示例 3：写客户邮件

```
你是一位有 5 年 B2B 销售经验的客户经理，擅长用不卑不亢的语气跟客户沟通。（角色）

请帮我回复一位重要客户的邮件。客户对我们上次提交的方案提出了修改意见，
说"价格偏高，希望再看看到底值不值"。（任务）

背景：
- 客户是一家 200 人规模的教育公司
- 我们的报价是 18 万/年，竞品报 12 万
- 我们多出来的价值：专属客户成功经理 + 无限次培训 + 自定义功能支持
- 我的目标：不降价，但可以加赠 2 个月服务期

要求：
- 先认可客户的顾虑，不要一上来就辩护
- 用具体对比说明价值差异，不要空洞地说"我们更好"
- 给出加赠方案作为台阶
- 语气友好但自信，不超过 300 字（要求）

输出格式：
邮件主题 + 邮件正文（输出格式）
```

## 公式简写版（日常快速使用）

不是每次都要写这么详细。日常快速使用时，可以简写：

```
作为[角色]，请[任务]。要求：[2-3个关键约束]。用[格式]输出。
```

**示例：**
```
作为资深编辑，请帮我把以下文章缩写到 500 字以内。
要求：保留核心观点和关键数据，删掉重复论述。用要点列表输出。
```

## 常见错误排查清单

| 问题 | 可能的原因 | 修改建议 |
|------|-----------|---------|
| 输出太空泛 | 角色太笼统 | 加上行业、经验年限、专长 |
| 答非所问 | 任务描述不清晰 | 用明确的动词，一次只给一个任务 |
| 风格不对 | 没有提要求 | 加上调性、禁忌、受众描述 |
| 格式混乱 | 没有指定输出格式 | 明确你要什么格式（表格/列表/结构） |
| 内容太长/太短 | 没有字数限制 | 加上具体的字数或条目数量要求 |

## 小结

**万能公式：角色 + 任务 + 要求 + 输出格式**

- 角色锚定方向——越具体越好
- 任务明确目标——动词开头，一事一令
- 要求划定边界——包括"不要什么"
- 格式控制结果——减少你的二次加工

记住：提示词不是在跟 AI 聊天，是在写一份精确的工作指令。你写得越清楚，AI 交出的活儿就越靠谱。
