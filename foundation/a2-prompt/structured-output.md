# 结构化输出控制：精准输出表格、清单、JSON 等格式

AI 默认的输出是一大段文字。但很多时候你需要的是一份能直接用的表格、一个清晰的待办清单、或者一段能直接粘贴进代码的 JSON。这篇文章教你如何精准控制 AI 的输出格式。

## 为什么要控制输出格式？

| 不控制格式 | 控制格式 |
|-----------|---------|
| 一大段文字，需要自己整理 | 直接可用，省去二次加工 |
| 信息混杂，找不到重点 | 结构清晰，一眼看到关键信息 |
| 无法直接粘贴到其他工具 | 可以直接导入表格/代码/系统 |
| 每次输出格式不一致 | 格式统一，方便对比和存档 |

## 六种常用输出格式及提示词写法

### 格式一：Markdown 表格

**适用场景：** 对比分析、数据汇总、方案评估

```
请对比分析以下 3 个项目管理工具：飞书项目、钉钉项目、Notion。

对比维度：价格、适用团队规模、核心功能、移动端体验、集成能力

请用 Markdown 表格输出，格式如下：
| 维度 | 飞书项目 | 钉钉项目 | Notion |
|------|---------|---------|--------|
| 价格 | ... | ... | ... |

每个单元格不超过 30 字，最后一行给出综合推荐。
```

**AI 输出效果：**

| 维度 | 飞书项目 | 钉钉项目 | Notion |
|------|---------|---------|--------|
| 价格 | 免费版可用，企业版按人数 | 免费版可用，专业版 ¥980/年 | 免费/Plus ¥48/人/月 |
| 适用规模 | 50-5000 人 | 10-10000 人 | 1-200 人 |
| 核心功能 | 多维表格+自动化 | 任务看板+审批流 | 灵活数据库+Wiki |
| 移动端 | 体验好，功能完整 | 体验一般 | 基本可用，编辑受限 |
| 集成能力 | 飞书生态内强 | 钉钉生态内强 | API 开放，第三方集成多 |
| **推荐** | **大团队+飞书用户** | **大团队+钉钉用户** | **小团队+重度自定义** |

### 格式二：要点清单

**适用场景：** 待办事项、检查清单、要点总结

```
请帮我制定一份新产品上线前的检查清单。

产品：一个在线教育平台的新课程功能
上线时间：2 周后

请用以下格式输出，每项标注负责人和优先级：

- [ ] [检查项] | 负责人：[角色] | 优先级：[P0/P1/P2]

按阶段分组：
一、功能验证（上线前 2 周）
二、性能测试（上线前 1 周）
三、上线当天
四、上线后监控（上线后 1 周）
```

### 格式三：JSON

**适用场景：** 给开发用、数据对接、批量处理

```
请把以下用户反馈整理成 JSON 数组格式。

原始反馈：
1. "搜索功能太慢了，输入之后要等好几秒" —— 用户 A
2. "希望能加个深色模式，晚上看手机太刺眼" —— 用户 B
3. "会员价格能不能搞个季度套餐" —— 用户 C

输出格式要求：
[
  {
    "id": 1,
    "user": "用户标识",
    "feedback": "反馈原文",
    "category": "分类（性能/UI/商业化/功能/其他）",
    "priority": "high/medium/low",
    "suggested_action": "建议处理方式"
  }
]

严格输出合法 JSON，不要加额外说明文字。
```

### 格式四：大纲/层级结构

**适用场景：** 方案规划、课程设计、汇报大纲

```
请帮我搭建一个"AI 入门"在线课程的大纲。

目标学员：零基础的职场人士
课程目标：学完后能用 AI 工具提升日常工作效率
总课时：8 节课，每节 30 分钟

请用多级标题格式输出：
# 课程名
## 第 X 课：[课名]
### 学习目标
- [目标 1]
- [目标 2]
### 内容要点
1. [要点]
2. [要点]
### 课后练习
- [练习任务]

最后附一份"8 周学习路线图"表格。
```

### 格式五：对话/问答格式

**适用场景：** FAQ、模拟面试、客服话术

```
请帮我准备一份产品 FAQ，面向我们 App 的新用户。

产品：记账 App"随手记"，核心功能包括拍照记账、自动分类、月度报告。

请用以下格式输出，至少 10 个问答：

**Q：[用户可能问的问题]**
A：[简洁的回答，不超过 3 句话]

按以下分类组织：
一、基础使用（3 个 Q&A）
二、账户与数据（3 个 Q&A）
三、付费相关（2 个 Q&A）
四、技术问题（2 个 Q&A）
```

### 格式六：模板填充

**适用场景：** 批量生成格式统一的内容

```
请帮我为以下 5 个功能点各写一段产品描述。

产品：一款团队协作工具

功能列表：
1. 实时文档协作
2. 任务看板
3. 日程管理
4. 文件共享
5. 视频会议

请严格按照以下模板为每个功能生成描述（不要改动模板结构）：

---
### [功能名]
**一句话说明：** [8 个字以内概括功能]
**解决什么问题：** [1 句话描述痛点]
**怎么用：** [2-3 步操作说明]
**适合谁：** [目标用户]
---
```

## 格式控制的进阶技巧

### 技巧一：用示例锁定格式

只描述格式可能不够，给一个示例更保险：

```
请按以下格式输出竞品分析报告：

[示例]
---
## 竞品：Notion
- 定位：All-in-one 工作空间
- 核心用户：知识工作者、小团队
- 优势：极高的自定义灵活性
- 劣势：学习曲线陡峭
- 对我们的启示：可以借鉴其模板市场策略
---

现在请用完全相同的格式分析：[竞品名称]
```

### 技巧二：多格式组合

一个提示词里可以要求多种格式混合输出：

```
请分析我们产品的用户增长数据。

输出要求：
1. 先用一段话（100 字以内）总结整体趋势
2. 用表格列出月度关键数据（月份、新增用户、活跃用户、留存率）
3. 用要点列表列出 3 个核心发现
4. 用 JSON 格式输出异常数据点（月份、指标、异常值、可能原因）
```

### 技巧三：格式锁定 + 禁止自由发挥

```
请严格按照以下格式输出，不要添加任何额外的解释、总结或开头语。

直接从表格开始：

| 项目 | 当前值 | 目标值 | 差距 | 建议动作 |
|------|-------|-------|------|---------|
```

### 技巧四：条件格式

根据不同情况输出不同格式：

```
请分析以下客户反馈，判断类型后按对应格式输出：

- 如果是 BUG 反馈 → 输出：🐛 [优先级] | 问题描述 | 复现步骤建议
- 如果是功能建议 → 输出：💡 [可行性:高/中/低] | 功能描述 | 预期价值
- 如果是使用咨询 → 输出：❓ 问题 | 回答建议 | 相关文档链接

客户反馈列表：
[粘贴反馈内容]
```

## 格式控制常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| AI 不按格式输出 | 格式描述太笼统 | 给一个具体的示例 |
| 格式对了但内容差 | 只关注了格式忘了内容 | 格式和内容要求都要写 |
| JSON 格式有语法错误 | AI 偶尔会出错 | 加一句"严格输出合法 JSON，不要加额外文字" |
| 表格列数不对 | 没有明确指定列名 | 在提示词里写好完整的表头 |
| 输出带了解释性文字 | AI 自带"好的，以下是……" | 加一句"直接输出格式内容，不要加开头语" |

## 小结

控制输出格式的核心方法：

1. **明确指定格式**——直接说"用表格/JSON/清单输出"
2. **给示例**——比描述格式更有效
3. **写死模板**——对于格式统一的内容，直接给模板让它填
4. **禁止自由发挥**——加"不要加额外说明"防止 AI 画蛇添足
5. **多格式组合**——复杂任务可以混合多种格式

**记住：格式控制是提示词里投入产出比最高的一项优化。** 加一句话的格式要求，就能省掉你 10 分钟的整理时间。
