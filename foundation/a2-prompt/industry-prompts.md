# 行业专属提示词模板：办公/销售/设计/编程可直接套用

收藏这一篇就够了。下面是 4 大行业、20+ 个即拿即用的提示词模板。把方括号里的内容替换成你的实际情况，直接发给 AI。

## 一、职场办公

### 1. 周报/月报生成

```
你是一位职场写作专家。请根据以下工作内容，生成一份结构清晰的周报。

我的岗位：[岗位名称]
本周完成的工作：
- [工作事项 1]
- [工作事项 2]
- [工作事项 3]

下周计划：
- [计划事项 1]
- [计划事项 2]

需要协调的问题：[如果有就写，没有就写"无"]

输出格式：
一、本周工作总结（每项用一句话概括成果）
二、关键数据/进展（用要点列表）
三、遇到的问题及解决方案
四、下周工作计划（按优先级排列）
语调：简洁专业，突出成果，避免流水账。
```

### 2. 会议纪要整理

```
你是一位专业的行政助理。请把以下会议录音转写内容整理成结构化的会议纪要。

会议主题：[主题]
参会人员：[人员]
会议时间：[日期]

以下是会议原始记录：
[粘贴转写内容]

请输出：
1. 会议概要（3-5 句话总结）
2. 讨论要点（按议题分组）
3. 关键决议（明确写了"确定""同意"的结论）
4. 待办事项（谁负责、截止时间、交付物）
5. 下次会议安排（如果提到了的话）
```

### 3. 邮件撰写

```
请帮我写一封[商务/催办/感谢/道歉]邮件。

收件人：[对方身份，如"合作方项目负责人"]
关系：[如"初次联系"/"已合作半年"/"对方是上级"]
目的：[如"催促对方提交方案"]
背景：[简要说明上下文]
我的立场/诉求：[你希望对方做什么]

语调要求：[专业但不生硬 / 礼貌但有态度 / 轻松友好]
篇幅：[100字以内 / 200字左右 / 详细说明]
```

### 4. 方案汇报 PPT 大纲

```
你是一位资深咨询顾问。请帮我搭建一份[项目汇报/季度总结/新品发布]的 PPT 大纲。

汇报对象：[如"公司高管"/"客户"/"投资人"]
汇报时长：[如"15 分钟"/"30 分钟"]
核心内容：
- [要点 1]
- [要点 2]
- [要点 3]

请输出：
- 每页的标题和核心内容（1-2 句话）
- 建议配什么类型的图表或图示
- 总页数控制在 [X] 页以内
- 标注哪几页是重点页，需要多停留
```

## 二、销售与商务

### 5. 客户开发信

```
你是一位 B2B 销售文案专家。请帮我写一封客户开发信。

我的产品/服务：[一句话描述]
目标客户：[行业/规模/角色，如"电商行业年营收 1000 万以上的运营总监"]
客户痛点（已知的）：[如"获客成本持续上升"]
我们的差异化优势：[如"按效果付费，不成交不收费"]
期望的行动：[如"约 15 分钟电话了解需求"]

要求：
- 邮件标题给出 3 个选项（不同风格）
- 正文 150 字以内
- 不用任何销售套话和虚假紧迫感
- 开头用对方可能关心的事实或数据切入，不要自我介绍开头
```

### 6. 竞品话术应对

```
你是一位资深销售教练。请帮我准备竞品应对话术。

我们的产品：[产品名及核心卖点]
主要竞品：[竞品名]
竞品的优势（客户经常提的）：[列出 2-3 点]
我们的优势（竞品没有的）：[列出 2-3 点]

请针对以下客户常见的竞品对比问题，各准备一段话术（每段 3-5 句话）：
1. "XX（竞品）价格比你们便宜"
2. "XX 的功能看起来比你们多"
3. "我们领导更倾向于选 XX"

话术要求：
- 先认可客户的关注点，不要直接否定竞品
- 用具体数据或案例做对比
- 最后引导到我们的差异化价值上
```

### 7. 客户异议处理

```
你是一位销售心理学专家。请帮我分析以下客户异议并给出应对策略。

客户异议："[粘贴客户原话，如'你们的价格太高了']"
客户背景：[行业/规模/决策阶段]
我们的报价：[如"年费 5 万"]
已知信息：[如"客户预算 3 万"/"客户还没看过产品演示"]

请输出：
1. 这条异议背后的真实顾虑可能是什么（至少分析 2 种可能）
2. 针对每种可能，各给一段应对话术（不要超过 4 句话）
3. 如果客户仍然坚持，下一步的推进策略是什么
```

### 8. 销售跟进计划

```
你是一位销售流程管理专家。请帮我制定客户跟进计划。

产品/服务：[描述]
销售周期：[如"1-3 个月"]
当前阶段：[如"已做产品演示，客户表示有兴趣但需要内部审批"]

已知信息：
- 关键决策人：[如"CTO 张总，技术背景"]
- 担心的问题：[如"数据安全"]
- 下次沟通时间：[如"两周后"]

请输出一份跟进计划：
1. 接下来两周内应该做的 3-5 个关键动作
2. 每个动作的目的和预期效果
3. 每次跟进去的切入话题建议
4. 如果遇到常见拖延（"再想想""下个季度再说"）的应对策略
```

## 三、内容与设计

### 9. 小红书/短视频脚本

```
你是一位社交媒体内容策划师。请帮我写一篇[小红书图文/短视频脚本]。

主题：[如"职场新人如何用 AI 提高效率"]
平台：[小红书 / 抖音 / 视频号]
目标受众：[如"22-28 岁职场新人"]
我的风格偏好：[如"干货型，语速快"/"聊天型，亲切自然"]

输出要求：
- 标题：给 3 个标题选项（含数字和痛点关键词）
- 正文/脚本：控制在 [字数/时长] 以内
- 包含 2-3 个具体工具/方法推荐
- 结尾要有互动引导（提问/求点赞收藏）
- 如果是短视频脚本，标注每个镜头的画面建议
```

### 10. 品牌文案/Slogan

```
你是一位品牌策略创意总监。请帮我为以下产品创作品牌文案。

产品/品牌名：[名称]
产品定位：[如"面向小团队的轻量级项目管理工具"]
核心卖点（最多 3 个）：
- [卖点 1]
- [卖点 2]
目标用户：[画像]
品牌调性：[如"温暖可靠"/"极客酷炫"/"轻松有趣"]

请输出：
1. 3 条 Slogan（各不超过 10 个字）
2. 1 段品牌故事（100 字以内）
3. 3 条产品功能描述文案（各 1 句话，区别于竞品的表达方式）
```

### 11. 设计需求 Brief

```
你是一位设计项目经理。请帮我写一份设计需求 Brief。

项目类型：[如"产品详情页"/"品牌 VI"/"活动海报"]
产品/活动信息：[简述]
目标用户：[画像]
使用场景：[如"淘宝店铺首页"/"朋友圈广告"/"线下展会"]
参考风格：[描述或粘贴参考图链接]
必须包含的元素：[如"Logo"/"二维码"/"价格信息"]
尺寸/规格：[如"1080x1920px"]
交付时间：[日期]

请输出一份完整的 Brief 文档，包含：
1. 项目背景和目标
2. 目标用户画像
3. 视觉风格描述（色彩倾向、调性关键词、参考案例）
4. 必含元素清单
5. 尺寸和格式要求
6. 验收标准
```

## 四、产品与编程

### 12. 需求文档（PRD）

```
你是一位产品经理。请帮我写一份功能需求文档。

功能名称：[如"用户注册登录"]
产品类型：[如"Web 端 SaaS"/"移动端 App"]
背景：[为什么要做这个功能，解决什么问题]

已知需求：
- [需求点 1]
- [需求点 2]

请输出包含以下部分的 PRD：
1. 功能概述（目标和使用场景）
2. 用户故事（作为 XX，我想要 XX，以便 XX）
3. 功能流程（用文字描述主流程和异常流程）
4. 页面/交互说明（列出每个页面的关键元素）
5. 业务规则（边界条件和特殊情况）
6. 非功能性需求（性能/安全/兼容性）
```

### 13. 代码生成/调试

```
你是一位[语言/框架]高级开发工程师。

任务：[如"实现一个分页查询接口"/"修复以下代码的 bug"]

技术栈：[如"Python 3.11 + FastAPI + PostgreSQL"]
现有代码（如有）：
[粘贴代码]

要求：
- 遵循 [PEP8/团队规范] 代码风格
- 包含错误处理和边界情况处理
- 关键逻辑加注释（中文）
- 如果有多种实现方式，列出并对比优劣，推荐最优方案
```

### 14. 技术方案评审

```
你是一位技术架构师。请帮我评审以下技术方案。

项目背景：[简述]
方案概述：
[粘贴方案内容]

请从以下维度评审并打分（1-5 分）：
1. 技术可行性
2. 扩展性
3. 安全性
4. 成本（开发成本 + 运维成本）
5. 团队匹配度（当前团队是否能 hold 住）

对每个维度给出评分理由，最后给出：
- 3 个最关键的改进建议
- 是否建议通过（通过 / 有条件通过 / 不通过）
```

### 15. 数据分析报告

```
你是一位数据分析师。请帮我分析以下数据并撰写分析报告。

分析目的：[如"找出用户流失的原因"]
数据说明：
[粘贴数据或描述数据来源和字段]

请输出：
1. 数据概览（关键指标的汇总统计）
2. 核心发现（3-5 条有数据支撑的结论）
3. 异常值/趋势分析
4. 可视化建议（建议用什么图表展示哪些数据）
5. 基于数据的 3 条行动建议（具体可执行）
```

## 模板使用心法

| 心法 | 说明 |
|------|------|
| 先填必填项 | 方括号里的内容越具体，输出越精准 |
| 效果不好就加背景 | 补充行业、场景、用户画像等信息 |
| 迭代优于一次到位 | 第一版不满意，追问"请更 XX 一些" |
| 存成自己的模板库 | 把好用的提示词存到笔记工具里 |

以上就是 4 大行业的即用模板。建议你先挑 2-3 个最常用的存下来，用熟了再逐步扩展。
