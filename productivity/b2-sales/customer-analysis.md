# 客户分析：从聊天记录中提炼需求、判断意向、精准跟进

## AI 客户分析的核心价值

销售最头疼的不是没客户，而是 **客户信息散落在各处**：微信聊天、电话记录、邮件往来。AI 可以帮你从这些非结构化信息中快速提炼出：客户到底要什么、意向有多高、下一步该怎么做。

---

## 一、从聊天记录提炼客户需求

### 1.1 需求提炼 Prompt

```
请分析以下与客户的聊天记录，提炼客户需求：

[粘贴聊天记录]

请输出：
1. 核心需求（一句话概括客户最想要什么）
2. 具体需求列表（分点列出所有提到的需求）
3. 隐含需求（客户没有直接说但暗示的需求）
4. 痛点/顾虑（客户反复提到的问题或担忧）
5. 预算线索（如果有提及预算相关信息的）
6. 决策人信息（谁说了算、谁有影响力）
```

### 1.2 需求分析案例

**聊天记录示例：**

> 客户：我们公司最近人多了，原来的系统有点卡
> 销售：大概多少人呢？
> 客户：从50人涨到200人了，而且还在招
> 客户：老板说年底前要换新系统，预算大概20万
> 客户：之前用过XX家的，服务不行，响应太慢

**AI 输出：**

| 维度 | 分析结果 |
|------|---------|
| 核心需求 | 为200+人团队寻找替代系统 |
| 预算 | 约20万，年底前 |
| 痛点 | 旧系统卡顿、前供应商服务差 |
| 隐含需求 | 重视售后响应速度 |
| 决策人 | 老板拍板 |
| 时间紧迫度 | 中高（年底前） |

### 1.3 批量客户需求分析

当你有多个客户需要分析：

```
请分别分析以下3位客户的需求，用表格汇总：

客户A聊天记录：
[记录]

客户B聊天记录：
[记录]

客户C聊天记录：
[记录]

汇总表格：
| 客户 | 核心需求 | 预算 | 紧迫度 | 关键顾虑 |
```

## 二、客户意向判断

### 2.1 意向评分模型

```
请根据以下客户互动信息，评估客户购买意向：

[粘贴所有互动记录]

请按以下维度打分（1-5分）：
1. 需求明确度（客户知道自己要什么吗？）
2. 预算可行性（有预算且匹配我们的价格吗？）
3. 时间紧迫度（是否有明确的采购时间线？）
4. 决策权（联系人是决策者还是执行者？）
5. 竞争态势（是否在对比其他供应商？）
6. 互动积极性（回复速度、主动联系频率）

总分：__/30
意向等级：A（必跟）/ B（重点）/ C（培育）/ D（暂缓）
下一步建议：[具体行动]
```

### 2.2 意向等级判断标准

| 等级 | 特征 | 跟进策略 | 跟进频率 |
|------|------|---------|---------|
| A 级 | 需求明确+有预算+有决策权+有时间线 | 全力推进，快速出方案 | 每天或隔天 |
| B 级 | 需求明确但预算/时间/决策人不清晰 | 持续沟通，摸清关键信息 | 每周1-2次 |
| C 级 | 有需求但不紧急或预算不足 | 定期培育，提供价值内容 | 每月1-2次 |
| D 级 | 需求模糊或明显不匹配 | 保持联系，不投入太多精力 | 每季度1次 |

### 2.3 客户画像生成

```
请根据以下信息，生成一份客户画像：

[粘贴所有客户互动记录]

客户画像需包含：
1. 基本信息：公司规模、行业、联系人职位
2. 需求画像：核心需求、次要需求、隐性需求
3. 决策画像：决策流程、关键影响人
4. 沟通画像：偏好的沟通方式、回复习惯
5. 风险画像：可能的异议、已知顾虑
6. 机会画像：交叉销售/升级的可能性
```

## 三、精准跟进策略

### 3.1 跟进方案生成

```
请根据以下客户信息，制定个性化的跟进方案：

客户基本信息：[概况]
已沟通内容：[历史互动]
客户意向等级：[A/B/C]
当前卡点：[客户犹豫的原因]

请输出：
1. 下一步最佳行动（具体做什么）
2. 推荐的沟通内容/话术
3. 需要准备的资料
4. 预期的客户反应及应对
5. 后续2-3次的跟进节奏
```

### 3.2 跟进内容定制

| 客户阶段 | 跟进目的 | 推荐内容 | AI 帮你做 |
|---------|---------|---------|----------|
| 刚接触 | 建立信任 | 行业洞察、案例分享 | 生成行业短文 |
| 有兴趣 | 展示价值 | 产品演示、ROI计算 | 生成演示大纲 |
| 考虑中 | 消除顾虑 | 客户案例、试用方案 | 生成案例描述 |
| 决策前 | 推动成交 | 限时优惠、合同模板 | 生成报价邮件 |
| 成交后 | 深化关系 | 使用指南、增值服务 | 生成回访话术 |

### 3.3 跟进时机判断

```
以下是我和客户的互动时间线：
[粘贴互动记录]

请分析：
1. 客户的回复模式（多久回复一次、什么时间段活跃）
2. 建议的最佳跟进时间
3. 是否有被冷处理的迹象
4. 下次联系的最佳切入点
```

## 四、客户分级管理

### 4.1 批量客户分级

```
请根据以下客户列表，帮我进行ABC分级：

| 客户 | 行业 | 人数 | 预算 | 状态 | 最后联系 |

[粘贴客户列表]

分级标准：
- A级：预算充足+需求明确+决策人在谈
- B级：有需求+预算待确认
- C级：有潜在需求+暂无明确计划
- D级：不匹配或无回应

输出排序后的客户列表，并说明每级客户的跟进建议。
```

### 4.2 客户管理看板结构

| 字段 | 说明 | AI 辅助 |
|------|------|--------|
| 客户名称 | 公司+联系人 | — |
| 意向等级 | A/B/C/D | ✅ 自动评估 |
| 核心需求 | 一句话概括 | ✅ 从聊天提取 |
| 下一步 | 具体行动 | ✅ 自动建议 |
| 跟进日期 | 计划联系时间 | ✅ 智能推荐 |
| 状态 | 新接触/跟进中/待成交/已成交 | — |

## 五、实战：一份完整的客户分析报告

```
请根据以下所有客户信息，生成一份完整的客户分析报告：

[粘贴所有相关资料：聊天记录、邮件、电话记录等]

报告结构：
1. 客户概况
2. 需求分析
3. 意向评估
4. 竞争分析
5. 风险评估
6. 跟进建议（含时间线）
7. 成交概率预估
```

## 六、注意事项

1. **数据安全**：客户信息属于敏感数据，注意使用企业级AI工具
2. **定期更新**：客户意向会变化，建议每周重新评估
3. **人机结合**：AI 分析+销售直觉，两者结合效果最佳
4. **避免过度依赖**：AI 可能误判客户情绪，关键决策仍需人工确认

---

## 小结

AI 客户分析的核心价值是 **把散乱的信息变成结构化的洞察**。从聊天记录中提炼需求、判断意向、制定跟进方案——原来需要老销售的经验判断，现在 AI 能帮你做 80% 的初筛和分析。关键是：**持续记录客户互动信息，给 AI 足够的原始素材**。
