# 汇报与演示：写总结、周月报，搭建 PPT 大纲

## 为什么汇报是最值得用 AI 的场景？

职场人每周要花 2-4 小时写周报、做总结、准备 PPT。这些工作的特点是：**格式固定、信息已知、只需要组织和表达**——正是 AI 最擅长的。

---

## 一、周报/月报自动生成

### 1.1 周报 Prompt 模板

```
请帮我写一份周报，信息如下：

【本周完成】
1. [完成的任务1]
2. [完成的任务2]
3. [完成的任务3]

【进行中】
1. [正在做的任务1]
2. [正在做的任务2]

【下周计划】
1. [计划任务1]
2. [计划任务2]

【需要支持】
1. [需要的资源/协调]

要求：
- 语言简洁，突出成果
- 每项用一句话概括
- 可量化的加上数据
- 语气：专业、自信
```

### 1.2 从聊天记录/笔记生成周报

```
以下是我这周的工作记录（来自飞书/Notion/随手记），请整理成周报：
[粘贴零散记录]

要求：
1. 自动归类（完成的/进行中的/下周计划）
2. 提炼出3-5个关键成果
3. 标注数据亮点（如有）
4. 语言正式但不过度包装
```

### 1.3 月报/季度汇报进阶

```
请帮我写一份月度工作总结报告：

背景：
- 岗位：[你的岗位]
- 本月核心目标：[目标]
- 实际完成情况：[数据/成果]

报告结构：
1. 月度目标回顾（列出原定目标）
2. 关键成果展示（数据+对比）
3. 重点事项说明（做得好的和遇到困难的）
4. 下月工作计划（3-5个方向）
5. 需要协调的事项

风格：面向直属领导，突出价值，不过度邀功
```

### 1.4 周报质量对比表

| 维度 | 普通周报 | AI 辅助周报 |
|------|---------|------------|
| 结构 | 随意罗列 | 清晰分类 |
| 语言 | 口语化 | 专业简洁 |
| 数据 | 缺乏 | 自动提炼 |
| 重点 | 不突出 | 成果前置 |
| 耗时 | 30-60分钟 | 5分钟 |

## 二、工作总结

### 2.1 年度/半年度总结

**Prompt 模板：**

```
请帮我写一份年度工作总结：
- 岗位：[你的岗位]
- 部门：[部门名称]
- 年度关键词：[用3-5个词概括这一年]

核心成果（请帮我润色表达）：
1. [成果1及数据]
2. [成果2及数据]
3. [成果3及数据]

不足与反思：
1. [不足1]
2. [不足2]

明年计划：
1. [计划1]
2. [计划2]

要求：
- 先用数据说话，再用文字解释
- 语气客观，不卑不亢
- 控制在1000字以内
```

### 2.2 数据润色技巧

| 原始表达 | 润色后 |
|---------|-------|
| 用户增长了很多 | 用户量同比增长180%，突破10万 |
| 效率提高了 | 流程优化后处理时间从3天缩短至0.5天 |
| 完成了项目 | 如期交付XX项目，客户满意度评分9.2/10 |
| 解决了问题 | 排除XX故障，避免了约50万元潜在损失 |

### 2.3 让 AI 帮你"包装"成果

```
请帮我用更专业的表述重新描述以下工作成果：
[粘贴你的原始描述]

要求：
- 加入STAR法则（情境-任务-行动-结果）
- 突出业务影响
- 用数据量化（如果原始描述没有数据，用占位符标注需要补充的数据）
```

## 三、PPT 大纲搭建

### 3.1 从零生成 PPT 大纲

```
请帮我设计一份PPT大纲：

主题：[PPT主题]
场景：[向领导汇报/客户提案/内部分享/培训]
时长：[15分钟/30分钟/60分钟]
受众：[领导/客户/同事/新人]

要求：
- 控制在10-15页
- 每页写明标题和要点（3-5个bullet points）
- 标注哪页需要图表/数据支撑
- 开头要有吸引人的引入
- 结尾要有明确的结论/行动号召
```

### 3.2 不同场景的 PPT 结构

**汇报型PPT（10-15页）：**

```
第1页：封面（标题+日期+汇报人）
第2页：执行摘要（一页讲清核心结论）
第3-4页：背景/目标
第5-8页：核心内容（分模块展开）
第9-10页：数据/成果展示
第11-12页：问题与挑战
第13页：下步计划
第14页：总结
第15页：Q&A
```

**提案型PPT（15-20页）：**

```
第1页：封面
第2页：痛点/机会分析
第3-4页：方案概述
第5-8页：方案详细说明
第9-10页：案例/数据支撑
第11-12页：实施计划与时间线
第13-14页：团队介绍
第15-16页：预算与报价
第17页：风险与应对
第18页：总结与下一步
第19-20页：Q&A/附录
```

### 3.3 PPT 内容生成进阶

**为每一页生成详细内容：**

```
请根据以下PPT大纲，为每一页生成详细的演讲稿内容：
[粘贴大纲]

每页包含：
1. 页面标题
2. 核心要点（3-5条）
3. 演讲时的口述内容（约1分钟）
4. 视觉建议（配什么图/表）
```

### 3.4 PPT 工具推荐

| 工具 | 特点 | 适用场景 |
|------|------|---------|
| WPS AI | 免费，中文好 | 国内汇报 |
| Copilot | 一键生成PPT | Office用户 |

| 讯飞智文 | PPT+演讲稿 | 国内通用 |

## 四、汇报技巧：AI 帮你"讲"得更好

### 4.1 生成演讲稿

```
请根据以下PPT内容，生成一份15分钟的演讲稿：
[粘贴PPT大纲]

要求：
- 口语化，像在和朋友聊天
- 关键数据要强调（标注停顿处）
- 每个部分之间有过渡语
- 预判可能的提问，准备回答要点
```

### 4.2 Q&A 准备

```
我即将做一场关于 [主题] 的汇报，请预判领导可能提出的 10 个刁钻问题，并为每个问题准备 30 秒的回答要点。
```

## 五、避坑指南

| ❌ 常见错误 | ✅ 正确做法 |
|-----------|-----------|
| 直接粘贴AI输出 | 通读修改，加入真实数据 |
| 堆砌华丽词藻 | 用数据和事实说话 |
| 面面俱到没有重点 | 突出2-3个核心成果 |
| 忽视格式排版 | 统一字体、对齐、配色 |
| 只报喜不报忧 | 客观陈述+给出改进方案 |

---

## 小结

汇报和演示是职场 AI 的"杀手级场景"：格式固定、信息已知、只需组织表达。掌握周报/总结/PPT大纲的 Prompt 模板，每次汇报从 2 小时缩短到 20 分钟。**但记住：AI 出初稿，你出判断力。**
