# 通用场景：会议录音、聊天记录一键转纪要、生成待办清单

## 最被低估的 AI 用法

很多职场人用 AI 写文章、做策划，却忽略了最日常的需求：**会议纪要、聊天整理、待办清单**。这些看似简单的事情，每天要花 30-60 分钟，AI 可以帮你压缩到 3 分钟。

---

## 一、会议录音转纪要

### 1.1 完整工作流

```
录音 → 语音转文字 → AI 整理纪要 → 人工审核 → 发送
```

**推荐工具链：**

| 步骤 | 工具 | 说明 |
|------|------|------|
| 录音 | 手机录音/飞书会议/钉钉会议 | 内置转写功能 |
| 转写 | 飞书妙记/讯飞听见/通义听悟 | 自动生成逐字稿 |
| 整理 | ChatGPT/Claude/豆包 | 结构化输出纪要 |

### 1.2 纪要生成 Prompt

**基础版：**

```
请根据以下会议录音转写文本，整理一份结构化的会议纪要：

[粘贴转写文本]

要求：
1. 会议主题（一句话概括）
2. 参会人员（从文本中提取）
3. 核心讨论内容（分点，每点不超过50字）
4. 关键决策（明确写"决定了什么"）
5. 待办事项（责任人+截止时间）
6. 下次会议安排（如有提及）
```

**进阶版（带背景信息）：**

```
请根据以下会议转写，整理纪要：
[粘贴转写]

背景信息：
- 项目名称：XX项目
- 项目阶段：需求评审
- 关注重点：交付时间、资源分配

请特别标注：
- 存在分歧的点（用⚠️标记）
- 未形成结论的点（用❓标记）
- 明确的action item（用✅标记）
```

### 1.3 不同会议类型的纪要侧重

| 会议类型 | 纪要重点 | 输出格式 |
|---------|---------|---------|
| 周会/站会 | 进展、阻塞、计划 | 三栏式（上周/本周/风险） |
| 需求评审 | 需求列表、优先级、负责人 | 表格+状态标记 |
| 头脑风暴 | 所有想法、票选结果 | 清单+分类 |
| 客户会议 | 客户需求、承诺事项、跟进计划 | 需求表+行动清单 |
| 复盘会 | 做得好的/待改进/行动项 | 三段式 |

## 二、聊天记录整理

### 2.1 微信群聊天记录整理

```
请帮我整理以下微信群聊天记录，提取关键信息：

[粘贴聊天记录]

要求：
1. 讨论主题（1-2个词概括）
2. 核心结论（不超过3条）
3. 分配的任务（谁负责什么）
4. 需要关注的风险或问题
5. 未达成一致的事项
```

### 2.2 多人聊天记录→结构化表格

```
请将以下聊天记录整理为表格：

| 发言人 | 核心观点 | 立场（支持/反对/中立）| 理由 |

聊天记录：
[粘贴记录]
```

### 2.3 聊天记录压缩

**场景**：100条群聊消息，你只想知道结论。

```
以下是一个工作群200条聊天记录，请：
1. 用3-5句话总结讨论的核心内容
2. 列出最终形成的结论（如果有的话）
3. 列出所有提到需要做的事情
4. 标注谁被@了但没回复

[粘贴聊天记录]
```

## 三、待办清单生成

### 3.1 从会议/聊天中提取待办

```
请从以下内容中提取所有待办事项，并按以下格式输出：

| 序号 | 任务 | 负责人 | 截止时间 | 优先级（高/中/低） |

[粘贴会议纪要或聊天记录]

优先级判断规则：
- 有明确截止时间的 → 高
- 别人依赖这个任务的 → 高
- 自身需要完成的 → 中
- 可以延后的 → 低
```

### 3.2 待办清单模板

**日待办模板：**

```
请帮我生成今日待办清单：
- 今日必做：[列举任务]
- 本周需推进：[列举任务]
- 待确认：[列举需要别人回复的事项]

要求：
- 按优先级排序
- 每个任务标注预计耗时
- 最后给出今日时间分配建议
```

### 3.3 GTD 与 AI 结合

| GTD 步骤 | AI 能做什么 | Prompt 关键词 |
|---------|-----------|-------------|
| 收集 | 从聊天/邮件中提取待办 | "提取所有需要做的事" |
| 整理 | 分类、标注优先级 | "按紧急/重要分类" |
| 组织 | 排序、分配时间 | "安排今日工作顺序" |
| 回顾 | 检查完成情况 | "哪些任务已过期" |
| 执行 | （人工执行） | — |

## 四、其他高频通用场景

### 4.1 读书/文章摘要

```
请帮我总结以下文章的核心要点（不超过5条）：
[粘贴文章]
每条控制在30字以内，按重要性排序。
```

### 4.2 信息对比

```
请帮我对比以下两个方案的优劣：
方案A：[描述]
方案B：[描述]

用表格呈现：
| 维度 | 方案A | 方案B |
|------|------|------|
| 成本 | ... | ... |
| 效率 | ... | ... |
| 风险 | ... | ... |
最后给出推荐建议和理由。
```

### 4.3 文本翻译+本地化

```
请将以下内容翻译为中文，注意：
- 不是字面翻译，要符合中文表达习惯
- 专业术语保留英文并附中文注释
- 调整语序使中文读起来自然

[粘贴英文内容]
```

## 六、注意事项

1. **录音需知情**：录制会议前告知参会者
2. **敏感信息过滤**：整理纪要前检查是否包含密码、薪资等敏感内容
3. **人名核对**：AI 可能会搞混相似的名字，务必人工检查
4. **结论确认**：AI 整理的结论需要会议主持人确认，避免误读

## 小结

会议纪要、聊天整理、待办提取——这些每天重复的小事，是 AI 最好用的场景。不需要复杂的 Prompt，粘贴内容+说清楚你要什么格式就够了。**每天节省 30 分钟，一年省出 180 小时。**
