# 邮件类：生成商务邮件、自动回复、跟进话术

## AI 写邮件的三大优势

1. **速度**：从 30 分钟缩短到 2 分钟
2. **得体**：AI 擅长把握商务礼仪和语气
3. **一致性**：团队邮件风格统一

---

## 一、商务邮件生成

### 1.1 通用邮件模板

**Prompt 模板：**

```
请帮我写一封商务邮件：
- 收件人：[客户/供应商/合作伙伴/领导]
- 目的：[询价/报价/合作邀约/问题反馈/感谢]
- 关键信息：[具体内容]
- 语气：正式/友好/委婉/直接
- 语言：中文/英文
- 字数：100-300字
```

### 1.2 高频邮件场景与 Prompt

**场景一：报价邮件**

```
请写一封报价邮件：
- 产品/服务：企业级SaaS系统
- 报价：年费 12 万元（含10个账号）
- 包含：产品核心功能、服务内容、付款方式
- 附带限时优惠：签约即送3个月免费使用期
- 语气专业但不过于生硬
```

**场景二：催回复邮件**

```
请帮我写一封委婉的跟进邮件：
- 背景：上周一给客户发了方案，至今未回复
- 目的：友好地提醒对方查看并反馈
- 不要给对方压力，但要有推进感
- 语气：礼貌、专业
```

**场景三：道歉邮件**

```
请帮我写一封道歉邮件：
- 背景：项目交付延迟了一周
- 原因：技术团队人手不足（不需要说太细）
- 已采取措施：增加了2名开发人员，重新排期
- 新交付日期：下周五
- 语气：诚恳、负责任、不推诿
```

### 1.3 邮件风格对照表

| 语气 | 适用场景 | 特征 |
|------|---------|------|
| 正式 | 政府机构、首次合作 | 敬语、长句、格式完整 |
| 友好 | 老客户、日常沟通 | 口语化、适当表情 |
| 委婉 | 催款、拒绝、投诉 | 先肯定、后转折、给台阶 |
| 直接 | 内部沟通、紧急事项 | 短句、要点清晰、无废话 |

## 二、英文邮件

### 2.1 中英双语一键生成

```
请帮我写一封英文商务邮件：
- 收件人：海外供应商
- 目的：确认订单细节，询问交货时间
- 关键信息：订单号 #20260315，产品 500 件，约定价格 $12/件
- 语气：专业、礼貌
- 同时提供中文对照版本
```

### 2.2 英文邮件润色

```
请帮我润色以下英文邮件，使其更地道、更专业：
[粘贴英文草稿]

要求：
- 修正语法错误
- 优化用词（更商务化）
- 调整语气（更得体）
- 标注修改处及原因
```

### 2.3 常用英文邮件句型速查

| 场景 | 中式表达（避免） | 地道表达 |
|------|----------------|---------|
| 开场 | I am writing to... | Thank you for reaching out... |
| 请求 | Please give me... | Could you please share... |
| 催促 | Reply me soon | I'd appreciate your feedback by... |
| 结尾 | Waiting your reply | Looking forward to hearing from you |

## 三、自动回复模板

### 3.1 常见自动回复场景

**休假自动回复：**

```
请帮我写一封邮件自动回复（Out of Office）：
- 休假时间：3月20日至3月25日
- 回复时间：3月26日
- 紧急联系人：[姓名]，[手机号]
- 语气：专业简洁
- 中英双语
```

**收到确认回复：**

```
请帮我设计一个邮件收到确认模板：
- 确认已收到对方邮件
- 预计回复时间：1-2个工作日内
- 如果紧急可致电：[电话]
- 适用场景：客户询价、合作咨询
```

### 3.2 自动回复设置指南

| 邮箱系统 | 设置路径 | 推荐场景 |
|---------|---------|---------|
| Outlook | 文件→自动回复 | 休假、出差 |
| Gmail | 设置→常规→休假回复 | 休假 |
| QQ邮箱 | 设置→自动回复 | 日常收到确认 |
| 企业微信 | 设置→邮件→自动回复 | 休假 |

## 四、跟进话术体系

### 4.1 销售跟进邮件序列

```
请帮我设计一个5封邮件的客户跟进序列：
- 产品：[你的产品/服务]
- 客户阶段：刚收到报价后
- 节奏：第1天、第3天、第7天、第14天、第30天
- 每封邮件有不同的切入角度
- 最后一封是"告别邮件"（不买也没关系）
```

### 4.2 跟进邮件节奏表

| 时间 | 目的 | 核心内容 | 语气 |
|------|------|---------|------|
| 第1天 | 确认收到 | 补充资料、解答疑问 | 热情 |
| 第3天 | 价值强化 | 客户案例、数据支撑 | 专业 |
| 第7天 | 制造紧迫 | 限时优惠、库存有限 | 友好+紧迫 |
| 第14天 | 换角度切入 | 新功能、新案例 | 轻松 |
| 第30天 | 最后尝试 | 真诚告别+留门 | 坦诚 |

### 4.3 跟进话术避坑

| ❌ 错误做法 | ✅ 正确做法 |
|-----------|-----------|
| "您考虑得怎么样了？" | "想确认下您这边是否还有其他顾虑？" |
| "我们价格可以再谈" | "如果预算有压力，我们可以分期方案" |
| 每天发邮件 | 间隔3-7天，每次有新内容 |
| 只聊产品 | 分享行业资讯、提供价值 |

## 小结

邮件是职场最高频的沟通方式之一。用 AI 处理邮件，核心是 **把重复场景模板化**：报价、跟进、道歉、感谢、催回复……每个场景准备一套 Prompt 模板，日常直接套用，2 分钟搞定一封高质量邮件。
