# 内容创作：公众号长文、小红书笔记、视频脚本

## AI 内容创作的核心思路

AI 不是替你创作，而是帮你 **提效 5-10 倍**。你的角色从"写作者"变成"编辑者"——给方向、审质量、调风格。

---

## 一、公众号长文

### 1.1 选题到成稿全流程

**第一步：选题策划**

```
我运营一个关于 [职场效率/个人成长/行业分析] 的公众号，目标读者是 [25-35岁职场人]。
请帮我推荐 5 个本周热门选题，要求：
- 结合当前热点
- 有实用价值
- 标题有吸引力（数字+悬念+痛点）
```

**第二步：大纲生成**

```
请根据以下选题，生成一篇公众号文章的详细大纲：
选题：[粘贴选题]
要求：
- 开头用故事/数据/反常识引入（3选1）
- 正文分3-5个部分，每部分有小标题
- 每个部分包含：观点 + 案例/数据 + 小结
- 结尾有行动号召或金句
- 总字数：2000-3000字
```

**第三步：正文撰写**

```
请根据以下大纲，撰写完整的公众号文章：
[粘贴大纲]
风格要求：
- 口语化但不随意
- 适当使用短句和换行
- 每300字左右出现一个小标题或视觉分隔
- 文末引导关注/点赞
```

### 1.2 标题优化

```
请为以下文章生成 10 个标题方案，覆盖不同风格：
[粘贴文章摘要]

风格覆盖：
- 数字型：5个方法 / 3个误区
- 悬念型：为什么... / ...背后的真相
- 痛点型：还在...吗 / 别再...了
- 对比型：从...到... / ...vs...
```

### 1.3 公众号文章质量检查清单

| 维度 | 检查点 | AI 可辅助 |
|------|-------|----------|
| 标题 | 是否有点击欲望？ | ✅ 批量生成标题 |
| 开头 | 3秒内能否抓住读者？ | ✅ 生成多种开头 |
| 结构 | 逻辑是否清晰？ | ✅ 大纲优化 |
| 案例 | 是否真实可信？ | ⚠️ 需人工核实 |
| 金句 | 是否有传播力？ | ✅ 生成金句库 |
| 结尾 | 是否有行动号召？ | ✅ 生成CTA |

## 二、小红书笔记

### 2.1 爆款笔记公式

小红书笔记 = **吸睛标题 + 钩子开头 + 干货正文 + 互动引导** + 精美配图

**标题生成 Prompt：**

```
请帮我写 10 个小红书标题，主题是 [减脂餐/职场穿搭/读书笔记]：
- 包含emoji
- 20字以内
- 使用数字、感叹号制造紧迫感
- 风格参考：xx亲测、xx避雷、xx必看
```

**正文模板：**

```
请帮我写一篇小红书笔记：
主题：[具体主题]
目标：种草/教程/分享/测评
要求：
- 开头设置悬念或共鸣（1-2句）
- 正文用分点罗列（带emoji序号）
- 每个点控制在30字以内
- 结尾引导互动（提问/征集）
- 总字数300-500字
- 适当使用空行增加可读性
```

### 2.2 小红书 vs 公众号内容适配

| 维度 | 小红书 | 公众号 |
|------|-------|-------|
| 字数 | 300-500字 | 2000-3000字 |
| 风格 | 轻松、emoji多 | 深度、结构化 |
| 配图 | 多图拼接、封面图 | 头图+文中插图 |
| 互动 | 评论区种草 | 文末引导关注 |
| 标题 | 20字内有冲击力 | 可稍长，重信息量 |

### 2.3 一键改稿（长文→小红书版）

```
请将以下公众号文章改写为小红书笔记风格：
[粘贴原文]
要求：
- 精简到400字以内
- 添加emoji
- 改为第一人称口吻
- 分点呈现核心内容
- 末尾加互动引导
```

## 三、视频脚本

### 3.1 短视频脚本（15-60秒）

```
请帮我写一个抖音/视频号的短视频脚本：
主题：[具体主题]
时长：30秒左右
风格：[知识科普/生活分享/搞笑段子/种草推荐]
要求：
- 前3秒必须有钩子（制造悬念/提出问题/展示结果）
- 中间是核心内容（最多3个点）
- 结尾有引导（关注/点赞/评论）
- 标注画面建议和文字提示
- 用表格形式输出：时间 | 画面 | 台词 | 字幕
```

### 3.2 中长视频脚本（3-10分钟）

```
请帮我写一个B站/YouTube风格的中长视频脚本：
主题：[具体主题]
时长：5分钟左右
风格：[深度解读/教程/Vlog/测评]
结构要求：
1. 开场白（15秒）：引入+预告
2. 背景介绍（30秒）：为什么要聊这个
3. 核心内容（3-4分钟）：分3-4个部分
4. 总结升华（30秒）：观点+互动引导
- 每个部分标注建议的B-roll素材
```

### 3.3 脚本类型速选

| 视频类型 | 时长 | 核心结构 | AI 擅长度 |
|---------|------|---------|----------|
| 口播知识 | 30-60秒 | 钩子+观点+结论 | ⭐⭐⭐⭐⭐ |
| 好物推荐 | 30-60秒 | 痛点+展示+优惠 | ⭐⭐⭐⭐ |
| 深度解读 | 5-10分钟 | 引入+分析+总结 | ⭐⭐⭐⭐ |
| 教程类 | 3-10分钟 | 问题+步骤+演示 | ⭐⭐⭐⭐⭐ |
| Vlog | 不定 | 事件+感受+互动 | ⭐⭐⭐ |

## 四、内容批量生产工作流

### 一鱼多吃策略

一次创作，多平台分发：

```
我有一篇关于 [主题] 的深度文章（约2000字），请帮我：
1. 提取3个核心观点，各生成一条朋友圈文案
2. 改写为一篇小红书笔记（400字）
3. 提取精华生成一个30秒短视频口播脚本
4. 生成5条微博内容（140字以内）

原文如下：
[粘贴原文]
```

### 效率对比

| 环节 | 传统方式 | AI 辅助 | 节省时间 |
|------|---------|---------|---------|
| 选题策划 | 1小时 | 10分钟 | 83% |
| 大纲撰写 | 30分钟 | 5分钟 | 83% |
| 正文初稿 | 2-3小时 | 20分钟 | 87% |
| 标题优化 | 30分钟 | 5分钟 | 83% |
| 多平台改编 | 2小时 | 20分钟 | 83% |

## 五、避坑指南

1. **不要直接发布 AI 初稿**——至少通读一遍，加入个人经历和观点
2. **警惕 AI 编造数据**——所有数字和案例需要核实
3. **保持个人风格**——让 AI 学习你的历史文章风格后再生成
4. **版权意识**——AI 生成的内容仍需查重，避免与已有内容雷同

---

## 小结

AI 内容创作不是"一键出稿"，而是"**AI 出初稿 + 人工精修**"。掌握不同平台的风格特点，用对 Prompt，效率可以提升 5 倍以上。关键是永远做内容的"最终把关人"。
