# 行政/人事效率化：快速撰写通知、制度，批量排版、改错

## 为什么行政/人事需要 AI？

行政和人事岗位每天要处理大量文书工作：通知公告、规章制度、考勤统计、合同模板……这些工作有 70% 以上是重复性劳动。AI 可以帮你：

- **5 分钟写完一份通知**（原来需要 30 分钟）
- **批量校对排版错误**（原来逐行检查要 1 小时）
- **一键生成制度初稿**（原来从零写要半天）

---

## 一、通知公告：从 30 分钟到 5 分钟

### 1.1 快速生成通知

**Prompt 模板：**

```
请帮我写一份公司通知，要求如下：
- 类型：放假通知 / 调岗通知 / 制度变更通知 / 会议通知
- 对象：全体员工 / 某部门 / 新入职员工
- 关键信息：[填入具体内容]
- 语气：正式 / 亲切 / 简洁
- 字数：200-500 字
```

**实操案例：**

```
请帮我写一份春节放假通知：
- 放假时间：2026年1月25日至2月2日，共9天
- 2月3日（周一）正常上班
- 节前需完成手头紧急工作
- 值班安排另行通知
- 语气正式，300字以内
```

### 1.2 通知类型对比

| 通知类型 | AI 擅长点 | 需人工补充 |
|---------|----------|-----------|
| 节假日通知 | 格式规范、日期计算 | 具体值班安排 |
| 人事变动通知 | 措辞得体、信息完整 | 实际人员信息 |
| 制度变更通知 | 逻辑清晰、新旧对比 | 具体制度条款 |
| 会议通知 | 时间地点格式化 | 实际议程细节 |

### 1.3 批量生成不同版本

```
请根据以下信息，分别生成邮件版和微信群发版两个版本的放假通知：
[粘贴通知内容]
要求：邮件版正式完整，微信版简洁带 emoji
```

## 二、规章制度：AI 辅助起草

### 2.1 制度起草 Prompt

```
请帮我起草一份 [考勤管理/差旅报销/办公用品领用] 制度：
- 公司规模：50-200人
- 行业：[互联网/制造业/服务业]
- 重点约束：[迟到早退/超标报销/浪费耗材]
- 包含：目的、适用范围、具体条款、处罚措施、生效日期
- 参考常见的制度框架
```

### 2.2 制度优化与完善

已有旧版制度？让 AI 帮你升级：

```
以下是我司现行的考勤制度，请帮我：
1. 检查是否有逻辑漏洞
2. 补充远程办公相关条款
3. 优化措辞使表述更严谨
4. 增加弹性工作制的说明

[粘贴旧版制度]
```

## 三、批量校对与排版

### 3.1 一键校对

**Prompt 模板：**

```
请帮我校对以下文本，检查并修正：
- 错别字和用词错误
- 标点符号不规范
- 数字/日期格式不统一
- 语句不通顺的地方

标注所有修改点，并说明修改原因：
[粘贴文本]
```

### 3.2 格式统一

```
请将以下内容统一格式：
- 标题层级：一、（一）1.（1）
- 数字使用中文还是阿拉伯数字保持一致
- 段首缩进两个字符
- 列表项统一使用"•"符号

[粘贴文本]
```

### 3.3 批量处理技巧

| 场景 | 操作方式 | 节省时间 |
|------|---------|---------|
| 10份合同改公司名 | 逐个替换 Prompt | 约 30 分钟 |
| 50人通讯录排版 | 一次粘贴让AI整理 | 约 20 分钟 |
| 会议纪要错别字 | 整段粘贴校对 | 约 5 分钟 |
| 年度报告格式统一 | 给模板让AI重排 | 约 15 分钟 |

## 四、合同与模板管理

### 4.1 合同模板生成

```
请帮我生成一份 [劳动合同/保密协议/服务合同] 模板：
- 适用场景：[具体业务]
- 需包含的条款：[列举关键条款]
- 参考标准合同格式
- 用 [ ] 标注需要填写的信息
```

### 4.2 合同要点审查

```
请帮我审查以下合同的关键条款，标注潜在风险点：
[粘贴合同内容]
重点关注：违约责任、付款条件、知识产权、保密条款
```

## 五、日常高频场景速查表

| 场景 | Prompt 关键词 | 预期输出 |
|------|-------------|---------|
| 写通知 | 类型+对象+关键信息+语气 | 完整通知文本 |
| 写制度 | 类型+规模+重点+结构 | 制度初稿 |
| 校对文本 | 粘贴文本+校对要求 | 修改标注版 |
| 排版统一 | 粘贴文本+格式要求 | 格式化文本 |
| 生成模板 | 合同类型+场景+条款 | 可用模板 |
| 翻译文件 | 粘贴文本+目标语言 | 翻译结果 |

## 六、注意事项

1. **隐私保护**：不要将员工个人信息（身份证号、薪资等）直接粘贴到公共 AI 工具中
2. **法律审核**：AI 生成的合同和制度必须经过法务审核
3. **文化适配**：AI 生成的内容需要根据公司文化进行调整
4. **版本管理**：保留每次修改的版本记录，方便回溯

---

## 小结

行政人事工作中有大量标准化、重复性的文书任务，AI 可以帮你完成 80% 的初稿工作。关键是学会给 AI 提供清晰的指令，然后花时间在"审核和微调"上，而不是"从零写起"。
