# 财务与数据整理：AI 处理 Excel 公式、对账核对、生成报表

## AI 能帮你做什么？

财务和数据整理工作充满重复劳动：写公式、对数据、做报表。AI 可以帮你：

- **写 Excel 公式**：描述需求，AI 直接给公式
- **数据核对**：粘贴数据，AI 找差异
- **生成报表**：给数据，AI 出图表描述和结构
- **自动化建议**：分析你的工作流，推荐自动化方案

---

## 一、Excel 公式生成

### 1.1 用自然语言描述需求

**核心思路**：不需要记公式，用大白话描述你要什么。

**Prompt 模板：**

```
我有一个 Excel 表格，请帮我写公式：
- 数据说明：A列是产品名，B列是单价，C列是数量，D列是折扣
- 需求：在E列计算每个产品的实际总价（单价×数量×折扣）
- 注意：折扣是百分比格式（如0.8表示八折）
```

AI 会返回：`=B2*C2*D2`，并解释每部分含义。

### 1.2 常见财务公式速查

| 需求 | 自然语言描述 | Excel 公式 |
|------|------------|-----------|
| 求和 | 计算B2到B50的总和 | `=SUM(B2:B50)` |
| 条件求和 | 统计"已付款"的金额总和 | `=SUMIF(C2:C50,"已付款",B2:B50)` |
| 多条件统计 | 统计A部门Q1的销售额 | `=SUMIFS(D:D,A:A,"A部门",C:C,"Q1")` |
| 查找匹配 | 根据产品编号找价格 | `=VLOOKUP(A2,价格表!A:B,2,0)` |
| 日期计算 | 计算两个日期之间的天数 | `=DATEDIF(A2,B2,"D")` |
| 百分比 | 计算同比增长率 | `=(B2-A2)/A2` |

### 1.3 复杂公式拆解

遇到复杂需求，让 AI 分步拆解：

```
请帮我写一个Excel公式，需求如下：
- 在Sheet1的D列，根据员工编号从Sheet2中查找对应的部门
- 如果找不到，显示"未分配"
- 如果部门是"销售部"，还要额外标记"*"

请先分步解释思路，再给出完整公式。
```

## 二、对账与数据核对

### 2.1 两份数据快速比对

**Prompt 模板：**

```
请帮我核对以下两份数据的差异：

【系统数据】
[粘贴数据]

【银行流水】
[粘贴数据]

请找出：
1. 金额不一致的记录
2. 只在一边存在的记录
3. 日期不匹配的记录
```

### 2.2 常见对账场景

| 对账类型 | 常见问题 | AI 辅助方式 |
|---------|---------|------------|
| 银行对账 | 时间差、金额差异 | 粘贴数据找差异 |
| 库存盘点 | 实物与账面不符 | 对比盘点表与系统数据 |
| 应收应付 | 漏记、重复记账 | 按客户/供应商分类比对 |
| 费用报销 | 超标、重复提交 | 对比政策标准与实际报销 |

### 2.3 对账公式推荐

**标记差异：**

```
请帮我写一个公式：
- 对比A列（系统金额）和B列（银行金额）
- 如果差异超过1元，在C列显示"差异"+差异金额
- 如果一致，显示"√"
```

AI 返回：`=IF(ABS(A2-B2)>1,"差异"&TEXT(ABS(A2-B2),"#,##0.00"),"√")`

## 三、报表生成

### 3.1 数据汇总报告

```
请根据以下数据，生成一份月度费用分析报告：
[粘贴月度费用数据]

报告需包含：
1. 总费用及环比变化
2. 各部门费用排名
3. 超预算项目标注
4. 费用占比分析
5. 下月费用预测
6. 节支建议

格式：适合直接粘贴到邮件/PPT中
```

### 3.2 报表结构设计

| 报表类型 | 核心指标 | 推荐结构 |
|---------|---------|---------|
| 月度财务报表 | 收入/支出/利润 | 汇总表→明细表→趋势图 |
| 费用分析 | 各项费用占比 | 饼图+排名+对比 |
| 预算执行 | 预算vs实际 | 进度条+差异标注 |
| 应收账款 | 账龄分析 | 分层统计+风险标注 |

### 3.3 AI 生成图表描述

AI 本身不能直接生成 Excel 图表，但可以告诉你**该做什么图**：

```
请根据以下数据，告诉我应该用什么图表来展示：
[描述数据内容]

要求：
- 推荐最合适的图表类型
- 说明选择理由
- 给出图表标题和坐标轴标签建议
```

## 四、数据处理自动化

### 4.1 数据清洗

```
请帮我清洗以下数据：
[粘贴数据]

需要处理：
1. 去除重复项
2. 统一日期格式（YYYY-MM-DD）
3. 去除空格和特殊字符
4. 补全缺失值（用均值/上一行/指定值）
5. 返回清洗后的数据
```

### 4.2 数据格式转换

| 原始格式 | 目标格式 | AI 操作 |
|---------|---------|--------|
| PDF 表格 | Excel 格式 | 提取数据并整理为表格 |
| 图片中的表格 | 可编辑文本 | OCR + 格式化 |
| 多个Excel合并 | 单一汇总表 | 合并+去重+排序 |
| 非结构化文本 | 结构化表格 | 提取关键字段 |

### 4.3 效率提升对比

| 任务 | 传统耗时 | AI 辅助耗时 | 节省 |
|------|---------|------------|------|
| 写复杂公式 | 30-60分钟 | 2-5分钟 | 90% |
| 数据核对（100行） | 1-2小时 | 10分钟 | 85% |
| 生成月度报告 | 半天 | 30分钟 | 80% |
| 数据清洗 | 1-3小时 | 15分钟 | 85% |

## 五、财务 AI 使用注意事项

1. **数据安全**：不要将公司完整财务数据上传到公共 AI 平台
2. **公式验证**：AI 生成的公式务必用小数据集测试后再大面积使用
3. **小数精度**：财务数据注意四舍五入规则，AI 可能不按会计准则处理
4. **审计追溯**：保留原始数据和公式，方便审计追溯
5. **合规性**：报表格式需符合公司/行业规范，AI 生成的是初稿

## 小结

财务和数据工作中，AI 最擅长的是 **公式生成、数据核对、报表撰写** 三个方向。不需要成为 Excel 专家，用自然语言描述需求，AI 帮你翻译成公式。关键是：**先小数据验证，再大规模使用**。
