# 报告生成：自动生成数据分析报告、复盘总结、节省撰写时间

## 为什么用 AI 生成报告？

写报告是最耗时间的工作之一——整理数据、搭框架、写分析、配图表、反复修改格式。AI 可以把 **4 小时的报告压缩到 30 分钟**。

## 核心应用场景

| 报告类型 | 传统耗时 | AI 辅助耗时 | AI 做什么 |
|---------|---------|-----------|---------|
| 周报/月报 | 2-4 小时 | 20-30 分钟 | 框架 + 分析 + 文字 |
| 项目复盘 | 3-5 小时 | 30-45 分钟 | 结构化总结 + 经验提取 |
| 数据分析报告 | 4-8 小时 | 1-2 小时 | 数据解读 + 结论 + 建议 |
| 竞品分析 | 半天 | 1 小时 | 对比框架 + 差异分析 |
| 年度总结 | 1-2 天 | 2-3 小时 | 全年回顾 + 亮点 + 规划 |

## 一、周报/月报自动生成

### Prompt 模板

```
请根据以下数据生成本周工作周报：

本周核心数据：
- [指标1]: [数值]（环比 [变化]）
- [指标2]: [数值]（环比 [变化]）

本周完成事项：
[列出 3-5 项]

遇到的问题：
[列出 1-2 项]

下周计划：
[列出 2-3 项]

周报格式：
1. 一句话总结本周
2. 核心数据变化（表格形式）
3. 重点工作回顾
4. 问题与风险
5. 下周计划
6. 需要的支持（如有）
```

### 数据驱动的月报模板

```
请生成 [X] 月度业务分析报告：

一、整体表现
- 本月 GMV: [数值]，环比增长 [X]%
- 本月新增客户: [数值]
- [其他核心指标]

二、分渠道/产品表现
[粘贴分类数据]

三、亮点与问题
[列出已知的亮点和问题]

四、下月计划
[简要描述方向]

要求：
1. 每个数据配一句话解读
2. 用加粗标注关键数字
3. 问题部分给出具体建议
4. 总字数 800-1200 字
```

### 周报"精简版"模板（给老板的）

```
请把以下周报压缩为 5 句话以内的精简版，只保留老板最关心的：

原始周报：
[粘贴完整周报]

精简原则：
1. 先说结果（数字）
2. 再说最大的 1 个亮点
3. 最后说最大的 1 个风险/需要决策的事
```

## 二、项目复盘报告

### Prompt 模板

```
请帮我写一份项目复盘报告：

项目名称：[项目名]
项目周期：[开始日期] - [结束日期]
项目目标：[原定目标]
实际结果：[实际达成]

复盘框架：
1. 目标回顾（原定目标 vs 实际结果）
2. 做得好的 3 件事
3. 做得不好的 3 件事
4. 关键教训（5 条以内）
5. 下次可以改进的具体措施
6. 团队表扬（谁做了什么贡献）

参与人：[列出]
预算/成本：[如有]
```

### 活动复盘专用模板

```
请为以下营销活动写复盘报告：

活动名称：[名称]
活动时间：[时间]
活动形式：[如：直播/促销/线下活动]

数据结果：
- 参与人数: [X]
- 转化人数: [X]
- 总营收: [X]
- ROI: [X]

复盘要点：
1. 哪个环节效果最好
2. 哪个环节流失最多
3. 如果再做一次，3 个改进点
4. 可复用的经验
5. 总体评分（1-10）
```

## 三、数据分析报告

### Prompt 模板

```
请根据以下数据，生成一份数据分析报告：

背景：[如：分析某产品上线 3 个月的表现]

数据：
[粘贴核心数据]

报告结构：
1. 执行摘要（200 字以内，给高层看）
2. 数据概览（关键指标表格 + 环比同比）
3. 趋势分析（整体走势判断）
4. 细分分析（按 [维度] 拆解）
5. 问题诊断（异常点 + 可能原因）
6. 结论与建议（3 条具体可执行的建议）
7. 附录（数据明细）

语气：客观、数据驱动、避免主观猜测
```

### 报告质量检查 Prompt

```
请检查以下报告的质量：

[粘贴报告内容]

检查维度：
1. 数据是否前后一致（数字有没有矛盾）
2. 结论是否有数据支撑
3. 是否遗漏了重要信息
4. 语言是否清晰、无歧义
5. 格式是否统一

请列出所有问题并给出修改建议。
```

## 四、竞品分析报告

### Prompt 模板

```
请生成一份竞品分析报告：

我方产品：[产品名 + 简要介绍]
竞品列表：
1. [竞品A]
2. [竞品B]
3. [竞品C]

以下是我搜集的数据：
[粘贴对比数据或描述]

报告框架：
1. 市场格局概述
2. 产品功能对比（表格）
3. 定价对比
4. 各自优劣势（SWOT 简版）
5. 我们的差异化机会
6. 3 条具体行动建议
```

## 五、报告格式美化

### Prompt 模板

```
请将以下报告内容重新排版，使其更专业：

[粘贴报告原始内容]

要求：
1. 使用 Markdown 格式
2. 层级清晰（最多 3 级标题）
3. 关键数字用 **加粗**
4. 每个章节不超过 300 字
5. 添加章节间过渡句
6. 总字数控制在 [X] 字以内
```

## 实操建议

1. **固定报告模板**：每种报告建一个 Prompt 模板存档，下次直接套用
2. **先数据后分析**：先把数据丢给 AI，让它分析完再组织成报告
3. **人工润色**：AI 生成初稿后，花 10 分钟调整语气和重点
4. **积累报告库**：把好报告存下来，下次 AI 可以参考风格

## 常见问题

**Q：AI 生成的报告直接交上去行吗？**
A：建议作为初稿，人工过一遍关键数字和结论再提交。AI 负责框架和文字，人负责把关准确性。

**Q：数据不多也能写报告吗？**
A：可以。即使只有几个关键数字，AI 也能帮你搭框架、写分析、补建议。但数据越丰富，分析越有深度。

**Q：怎么让 AI 写的报告不像机器写的？**
A：在 Prompt 中加入"语气像写邮件给同事"、"避免套话"等指令，生成后手动调整几个关键句子，就会自然很多。
