# 可视化：生成图表让数据直观

## 为什么数据可视化很重要？

一张好图表胜过 1000 字说明。但很多人做图表的痛点是：

- 不知道用什么图表类型
- Excel/Numbers 操作繁琐
- 做出来的图表不好看、看不懂

AI 可以帮你：**选对图表、生成代码、优化呈现**。

## 一、选择正确的图表类型

选错图表是数据可视化最常见的错误。

### 图表选择速查表

| 你想展示什么 | 推荐图表 | 适用场景 |
|------------|---------|---------|
| 趋势变化 | 折线图 | 月度销售额、用户增长 |
| 对比差异 | 柱状图/条形图 | 各产品销量、各部门业绩 |
| 占比构成 | 饼图/环形图 | 市场份额、费用构成 |
| 分布情况 | 直方图/箱线图 | 客单价分布、年龄分布 |
| 相关关系 | 散点图 | 广告费 vs 销售额 |
| 多维对比 | 雷达图 | 产品多维度评分对比 |
| 流程转化 | 漏斗图 | 转化漏斗、招聘流程 |
| 时间安排 | 甘特图 | 项目进度 |
| 地理分布 | 地图 | 各城市销售、区域分布 |

### Prompt：帮你选图表

```
我有以下数据，想做成图表展示给 [受众：如老板/客户/团队]：

数据内容：[描述你的数据]
展示目的：[如：证明增长趋势 / 对比竞品 / 展示构成]

请推荐最合适的图表类型（1-2种），说明理由，并给出设计建议（颜色、标注重点等）。
```

## 二、用 AI 生成图表代码

最实用的方式：让 AI 生成 Python 代码，直接跑出图表。

### Prompt 模板

```
请用 Python matplotlib/seaborn 生成一张 [图表类型]：

数据：
[粘贴数据或描述]

要求：
1. 图表标题：[标题]
2. X轴标签：[标签]
3. Y轴标签：[标签]
4. 配色：[如：蓝色系 / 企业VI色 / 专业商务风]
5. 标注关键数据点
6. 输出为 PNG，分辨率 300dpi
7. 图表大小：12x6 英寸
8. 中文字体支持（使用 SimHei 或其他中文字体）
```

### 柱状图示例

```
请生成一张柱状图，对比各产品线Q1销售额：

数据：
- 产品A：35万
- 产品B：28万
- 产品C：42万
- 产品D：19万
- 产品E：31万

要求：
1. 从高到低排序
2. 最高柱用红色标注
3. 每个柱上方显示具体数字
4. 标题："2024年Q1各产品线销售额（万元）"
5. 简洁商务风格
```

### 折线图示例

```
请生成一张折线图，展示月度GMV趋势：

数据：
[粘贴12个月的数据]

要求：
1. 主线为实线蓝色
2. 添加趋势线（虚线）
3. 标注最高点和最低点
4. 在关键节点标注事件（如"双11"、"618"）
5. 添加平均值参考线（灰色虚线）
6. 标题含时间范围
```

### 漏斗图示例

```
请生成一张转化漏斗图：

数据：
- 访问：10000人
- 注册：3000人
- 加购：1500人
- 下单：800人
- 支付：650人

要求：
1. 每一层标注人数和转化率
2. 层之间标注流失率
3. 配色从蓝到红渐变
4. 标注整体转化率
```

## 三、数据表格美化

不是所有数据都需要图表，**一张好表格也能很直观**。

### Prompt 模板

```
请将以下数据整理为一张美观的 Markdown 表格：

原始数据：
[粘贴数据]

美化要求：
1. 关键数字用加粗标注
2. 最大的3个数字标为 🟢
3. 最小的3个数字标为 🔴
4. 添加"排名"列
5. 添加"环比变化"列（如果数据支持）
6. 表格下方添加一句话总结
```

### 条件格式化建议

```
请根据以下表格数据，给出条件格式化建议：

[粘贴表格]

针对每个数值列，建议：
1. 用什么颜色标红（低于什么值）
2. 用什么颜色标绿（高于什么值）
3. 是否需要数据条/图标集
4. 整体配色建议
```

## 四、数据大屏/仪表盘设计

### Prompt 模板

```

需要展示的指标：
- [指标1：如 实时GMV]
```

## 五、图表优化与避坑

### 常见图表错误

| 错误 | 问题 | 修正 |
|------|------|------|
| Y轴不从0开始 | 夸大差异 | 柱状图Y轴必须从0开始 |
| 3D效果 | 歪曲数据 | 不用3D，2D更准确 |
| 颜色过多 | 眼花缭乱 | 同一图表不超过5种颜色 |
| 饼图切片太多 | 无法比较 | 超过5项用柱状图 |
| 缺少标题 | 不知道看什么 | 每张图表都有明确标题 |
| 字体太小 | 看不清数字 | 关键数字至少 12pt |

### Prompt：图表优化

```
请审查以下图表设计，指出问题并给出优化建议：

图表描述：[描述你打算做的图表]
数据：[粘贴数据]
受众：[如：给老板看的月度汇报]

审查维度：
1. 图表类型是否合适
2. 数据展示是否准确
3. 颜色和标注是否清晰
4. 是否有误导性
5. 能否一眼看出核心结论
```

## 六、快速生成可用图表的方案

| 方案 | 难度 | 适用场景 | 步骤 |
|------|------|---------|------|
| AI 生成 Python 代码 | ⭐⭐ | 定制化需求强 | AI 生成代码 → 运行 → 出图 |
| AI 生成 Excel 公式 | ⭐ | 简单图表 | AI 给公式 → 粘贴到 Excel → 插入图表 |
| AI 生成 Mermaid 图表 | ⭐ | 流程图/简单图表 | AI 写 Mermaid 代码 → 渲染 |
| AI 推荐 + 手动制作 | ⭐ | 日常汇报 | AI 告诉你怎么做 → 自己操作 |

### Mermaid 图表 Prompt

```
请用 Mermaid 语法生成一个 [图表类型]，数据如下：

[数据]

要求：简洁、标注清晰、可直接渲染。
```

## 实操建议

1. **先定目的再做图**：想清楚"要让看的人得出什么结论"，再选图表
2. **一张图一个信息**：不要把 10 个指标塞进一张图
3. **常用图表建模板**：月报、周报用固定的图表样式，AI 生成后直接复用
4. **给 AI 看图反馈**：生成后截图给 AI，让它帮你优化

## 常见问题

**Q：我不会 Python，能用 AI 做图表吗？**
A：可以。让 AI 生成代码后，你只需要复制粘贴运行。或者用 AI 生成 Excel 图表的操作步骤，手动在 Excel 里做。

**Q：AI 生成的图表直接用在汇报里够专业吗？**
A：大部分场景够用。如果需要更精美的效果，可以在 AI 生成的基础上用设计工具微调。

**Q：数据更新了怎么办？**
A：把 AI 生成的代码存下来，下次只需要替换数据部分重新运行即可。或者让 AI 帮你写成脚本，一键刷新。
