# 全流程制作：从选题到发布的 AI 闭环工作流

把 AI 当作你的内容创作"流水线"。从选题策划、内容生成、配图设计到发布排期，每个环节都能用 AI 提效。本章给出完整的闭环工作流。

## 一、AI 内容创作闭环全景图

```
选题策划 → 内容生成 → 配图/剪辑 → 优化润色 → 发布排期 → 数据复盘
   ↑                                                        ↓
   └────────────── 反馈驱动迭代 ←─────────────────────────────┘
```

| 环节 | AI 能做什么 | 人工做什么 | 耗时占比 |
|------|-----------|-----------|---------|
| 选题策划 | 分析热点、生成选题库 | 判断方向、定调性 | 10% |
| 内容生成 | 写初稿、写脚本 | 创意把关、调整风格 | 15% |
| 配图/剪辑 | 生成图片、自动字幕 | 审美调整、品牌统一 | 30% |
| 优化润色 | SEO 优化、标题测试 | 最终审核 | 10% |
| 发布排期 | 自动排期建议 | 确认发布 | 5% |
| 数据复盘 | 分析数据、找规律 | 调整策略 | 30%（首次）/ 5%（后续） |

## 二、公众号长文全流程

### Step 1：选题与大纲

```
我想写一篇公众号文章，主题方向是 [主题]。
目标读者：[用户画像]
文章目的：[涨粉/种草/转化/品牌]

请帮我：
1. 生成 3 个标题备选（不同风格）
2. 给出完整的文章大纲（4-6 个小节）
3. 每个小节列出 2-3 个要点
4. 标注每个小节预估字数
5. 建议插入图片/图表的位置
```

### Step 2：分节撰写

不要让 AI 一次写完一整篇长文——质量不可控。分节写，每节打磨。

```
请根据以下大纲的第 [N] 节，写出完整段落：
[粘贴该节大纲]

要求：
1. 字数 300-500 字
2. 开头一句话总结本节核心观点
3. 用 1 个具体案例或数据支撑
4. 语言口语化但不失专业
5. 与上下文自然衔接
```

### Step 3：整合润色

```
以下是我写完的公众号文章全文：
[粘贴全文]

请帮我做最终润色：
1. 检查全文逻辑是否连贯
2. 删除重复表述
3. 优化开头（前 100 字决定打开率）
4. 优化结尾（加上行动号召）
5. 给出 SEO 建议：推荐关键词、摘要描述
6. 推荐封面图风格
```

### 公众号长文模板

| 部分 | 字数 | 要点 | AI 负责度 |
|------|------|------|----------|
| 标题 | 15-30 字 | 痛点+好奇心 | 90% |
| 摘要 | 50-80 字 | 一句话概括价值 | 80% |
| 开头 | 100-200 字 | 痛点场景+引入话题 | 70% |
| 主体 | 1500-2500 字 | 分节论述+案例 | 60% |
| 结尾 | 100-200 字 | 总结+行动号召 | 80% |

## 三、小红书笔记全流程

### Step 1：确定笔记类型

| 类型 | 结构 | 适合场景 | 互动目标 |
|------|------|---------|---------|
| 教程类 | 问题→方法→总结 | 分享技能 | 收藏 |
| 种草类 | 痛点→产品→效果 | 推荐产品 | 点赞+评论 |
| 对比类 | A vs B→分析→结论 | 帮用户决策 | 收藏+评论 |
| Vlog 类 | 场景→过程→感悟 | 日常生活 | 点赞+关注 |
| 清单类 | 主题→列表→总结 | 资源整理 | 收藏 |

### Step 2：生成笔记正文

```
请帮我写一篇小红书笔记：
主题：[主题]
类型：[教程/种草/对比/Vlog/清单]
目标用户：[用户画像]

要求：
1. 标题：15-20 字，包含数字和结果
2. 正文：400-600 字
3. 结构：痛点引入 → 分点内容 → 互动引导
4. 语言：闺蜜种草语气，多用 emoji
5. 话题标签：5-8 个（混合热门和精准标签）
6. 配图建议：说明需要几张图、每张图放什么内容
```

### Step 3：配图规划

```
我的小红书笔记主题是 [主题]，正文如下：
[粘贴正文]

请帮我规划 6 张配图：
- 第 1 张（封面）：[描述封面设计]
- 第 2-5 张（内容图）：每张对应一个要点
- 第 6 张（结尾图）：总结或互动引导

每张图请给出：
1. 文字内容（精简为关键词）
2. 布局建议（文字位置、背景色系）
3. 使用的 emoji 或图标建议
```

### 小红书笔记自查清单

| 检查项 | 是否达标 |
|--------|---------|
| 封面是否在 0.5 秒内传达主题？ | |
| 标题是否有数字和具体结果？ | |
| 正文是否分段且有 emoji？ | |
| 是否有明确的互动引导？ | |
| 话题标签是否 5 个以上？ | |
| 整体色调是否统一？ | |

## 四、短视频脚本全流程

### Step 1：确定脚本类型

| 类型 | 时长 | 结构 | 适合平台 |
|------|------|------|---------|
| 口播科普 | 30-60s | Hook + 3 个要点 + 引导 | 抖音/视频号 |
| 剧情/情景 | 30-60s | 冲突 + 反转 + 植入 | 抖音/TikTok |
| 测评/开箱 | 1-3min | 开箱 + 体验 + 总结 | 小红书/B站 |
| Vlog | 1-3min | 场景 + 过程 + 感悟 | 全平台 |

### Step 2：生成脚本

```
请帮我写一个短视频脚本：
类型：[口播/剧情/测评/Vlog]
主题：[主题]
时长：[30秒/60秒/3分钟]
平台：[抖音/小红书/视频号]

脚本包含：
1. 前 3 秒 Hook（一句话抓住注意力）
2. 主体内容（分段，标注每段时间）
3. 画面提示（每个镜头拍什么）
4. 字幕文本（逐句）
5. 结尾引导（关注/点赞/评论）
6. BGM 风格建议
```

### Step 3：脚本优化

```
以下是我的短视频脚本：
[粘贴脚本]

请帮我优化：
1. Hook 是否足够抓人？给出 3 个替代方案
2. 节奏是否紧凑？删掉可以去掉的废话
3. 是否有"金句"可以提炼？加粗标注
4. 结尾引导是否自然？不要硬广感
5. 预估完播率，给出提升建议
```

### 脚本质量评分标准

| 维度 | 权重 | 优秀 | 及格 | 差 |
|------|------|------|------|-----|
| Hook 吸引力 | 30% | 3 秒内让人停下 | 5 秒内 | 没有钩子 |
| 信息密度 | 25% | 每句都有价值 | 偶尔有废话 | 大量空话 |
| 节奏感 | 20% | 快慢有致 | 基本流畅 | 平铺直叙 |
| 引导转化 | 15% | 自然引导 | 有引导但生硬 | 无引导 |
| 情绪价值 | 10% | 引发共鸣 | 有情绪但不强 | 无情绪 |

## 五、发布前的最后检查

### 通用检查清单

| 检查项 | ✅/❌ |
|--------|-------|
| 标题是否有吸引力但不标题党？ | |
| 正文是否有错别字/语病？ | |
| 是否包含行动号召（CTA）？ | |
| 话题/标签是否正确？ | |
| 封面图是否清晰美观？ | |
| 发布时间是否在流量高峰期？ | |

### 平台特有检查

| 平台 | 额外检查项 |
|------|-----------|
| 小红书 | 首图是否 3:4？是否加了位置标签？ |
| 抖音 | 是否加了字幕？BGM 是否合规？ |
| 公众号 | 摘要是否填写？封面图是否 900x383？ |
| 视频号 | 视频是否竖屏？封面是否选了关键帧？ |

## 六、发布后：数据复盘闭环

```
以下是我上周发布的 5 篇内容数据：
[粘贴：标题、平台、播放/阅读量、完播率、互动率、涨粉数]

请帮我做数据复盘：
1. 哪篇表现最好？分析原因
2. 哪篇表现最差？问题出在哪
3. 整体内容方向是否需要调整？
4. 下周的选题和优化建议
5. 有没有可以做成系列的高潜力选题？
```

### 关键指标参考值

| 指标 | 优秀 | 及格 | 需改进 |
|------|------|------|--------|
| 完播率（短视频） | > 60% | 30-60% | < 30% |
| 互动率 | > 8% | 3-8% | < 3% |
| 收藏率（小红书） | > 5% | 2-5% | < 2% |
| 打开率（公众号） | > 10% | 5-10% | < 5% |
| 涨粉率 | > 2% | 0.5-2% | < 0.5% |

---

**总结**：全流程制作的核心是"分步 AI 化"。不要指望一个 Prompt 写出完美内容，而是把创作拆成选题→大纲→分段写→润色→配图→发布→复盘的流水线，每一步用 AI 提效。这个闭环跑通后，一个人就是一支内容团队。
