# 选题矩阵：用 AI 搭建永不断更的内容选题库

选题是内容创作的命脉。没有选题库，你每天都会面临"今天发什么"的焦虑。本章教你用 AI 搭建一套可持续运转的选题矩阵系统，从此告别灵感枯竭。

## 一、为什么需要选题矩阵？

### 传统选题 vs 矩阵选题

| 维度 | 传统选题 | 矩阵选题 |
|------|---------|---------|
| 来源 | 靠灵感、拍脑袋 | 系统化、数据驱动 |
| 数量 | 每次只想 1-2 个 | 一次生成 50-100 个 |
| 可持续性 | 经常断更 | 永不断更 |
| 质量 | 忽高忽低 | 稳定在及格线以上 |
| 效率 | 每天花 30 分钟想选题 | 每月花 1 小时维护 |

### 选题矩阵的四个维度

一个完整的选题矩阵包含四个维度：

1. **用户维度**：目标用户是谁？他们关心什么问题？
2. **场景维度**：用户在什么场景下需要你的内容？
3. **形式维度**：用什么内容形式呈现（图文/视频/直播）？
4. **时间维度**：什么时候发布？关联什么热点？

## 二、用 AI 搭建选题库：四步法

### 第一步：定义选题大类

用 AI 帮你梳理内容领域下的所有可写方向。

```
我是一个 [你的领域，如：减脂博主]，目标用户是 [用户画像]。
请帮我列出我所在领域的 10 大内容方向，每个方向给出 3 个子话题。
输出格式：
方向名 | 子话题1 | 子话题2 | 子话题3 | 用户痛点关键词
```

**示例输出（减脂领域）**：

| 方向 | 子话题 1 | 子话题 2 | 子话题 3 | 痛点关键词 |
|------|---------|---------|---------|-----------|
| 饮食控制 | 低卡食谱 | 外食怎么吃 | 欺骗餐安排 | 饿、馋、没时间做饭 |
| 运动方案 | 居家燃脂 | 姨妈期运动 | 小基数怎么练 | 懒、没场地、怕粗腿 |
| 心态管理 | 平台期怎么办 | 暴食后补救 | 减脂焦虑 | 焦虑、反复、自我否定 |

### 第二步：批量生成选题

拿到大类后，用 AI 批量扩展具体选题。

```
基于以下内容方向：[粘贴上一步的方向列表]
请为每个方向生成 10 个具体选题，要求：
1. 标题用小红书风格（数字+痛点+结果）
2. 覆盖教程类、经验分享类、避坑类、对比类四种类型
3. 每个选题标注适合的平台（小红书/抖音/公众号）
输出为表格
```

### 第三步：热点注入

用 AI 分析近期热点，将热点与你的选题库关联。

```
以下是本周热搜话题：[粘贴微博/抖音热搜关键词]
我的内容领域是 [你的领域]。
请帮我找出能与这些热点结合的选题，每个热点给出 2-3 个切入点。
要求：结合要自然，不能硬蹭。
输出格式：热点话题 | 结合切入点 | 建议标题 | 紧急程度（今天发/本周发）
```

### 第四步：生成排期表

```
我有以下 30 个选题：[粘贴选题列表]
请帮我安排一个月的内容排期，要求：
1. 每周 5 篇内容（工作日更新）
2. 周一三五发小红书，周二四发抖音/视频号
3. 热点选题优先安排在本周
4. 教程类和经验分享类交替发布
输出为周历表格
```

## 三、四类选题模板

### 模板 1：教程类

```
帮我写一个小红书教程选题，主题是 [主题]。
要求：
1. 标题包含数字和结果（如"3 步搞定 XX"）
2. 目标用户：[用户画像]
3. 内容结构：问题引入 → 分步教程 → 总结 + 引导互动
4. 预估阅读时间：3 分钟
```

### 模板 2：避坑类

```
帮我设计一个避坑类选题，领域是 [领域]。
要求：
1. 列出 [领域] 新手最容易犯的 5 个错误
2. 每个错误给出正确做法
3. 标题格式："千万别 XX，否则 XX"
4. 语气：朋友间的劝告，不要太严肃
```

### 模板 3：对比类

```
帮我设计一个对比类选题，对比 [A 方案] 和 [B 方案]。
要求：
1. 从效果、成本、难度、适合人群四个维度对比
2. 给出明确的推荐结论
3. 标题："XX vs XX，到底选哪个？"
4. 输出对比表格
```

### 模板 4：清单类

```
帮我设计一个清单类选题，主题是 [主题]。
要求：
1. 列出 10 个实用建议/工具/资源
2. 每项用一句话说明 + 为什么推荐
3. 标题格式："盘点 10 个 XX，第 X 个绝了"
4. 适合小红书和公众号
```

## 四、长视频 / 短图文的内容组合策略

不同内容形式适合不同目的。组合使用效果最佳。

### 内容形式矩阵

| 内容形式 | 适合平台 | 最佳用途 | 制作成本 | 流量特征 |
|---------|---------|---------|---------|---------|
| 15 秒短视频 | 抖音/TikTok | 吸引注意力、引流 | 低 | 爆发型 |
| 1-3 分钟视频 | 小红书/视频号 | 种草、测评 | 中 | 稳定型 |
| 图文笔记 | 小红书 | 教程、清单 | 低 | 长尾型 |
| 长图文 | 公众号 | 深度内容、信任建立 | 高 | 精准型 |
| 长视频（5min+） | B站/YouTube | 系列教程、品牌建设 | 高 | 复利型 |

### "一鱼多吃"策略

一个核心选题，拆解为多种形式：

```
我的核心选题是：[选题]
请帮我做"一鱼多吃"拆解：
1. 抖音 15 秒短视频脚本（只保留最炸的核心观点）
2. 小红书图文笔记（分 6 张图，每图一个要点）
3. 公众号长文大纲（展开为 2000 字深度文章）
4. 视频号 1 分钟精华版脚本
保持核心观点一致，但表达方式适配各平台风格
```

### 发布节奏建议

| 阶段 | 频率 | 内容类型 | 目标 |
|------|------|---------|------|
| 起号期（1-3 月） | 日更或 5 篇/周 | 短内容为主 | 测试选题方向 |
| 成长期（3-6 月） | 4-5 篇/周 | 短+长混合 | 建立内容壁垒 |
| 稳定期（6 月+） | 3-4 篇/周 | 精品化 | 提升单篇价值 |

## 五、选题库维护 SOP

### 每周维护（10 分钟）

1. 用 AI 扫描本周热点，补充 3-5 个热点选题
2. 删除已发布和过时的选题
3. 标记本周表现最好的选题类型，同类选题加权

### 每月更新（30 分钟）

```
以下是我上个月的数据表现：
[粘贴各平台数据：播放量、互动率、涨粉数]
请帮我分析：
1. 哪类选题表现最好？
2. 哪类选题需要淘汰？
3. 下个月建议重点做哪些方向？
4. 给出下个月的选题方向建议
```

## 六、实操案例：从零搭建选题库

以"职场穿搭博主"为例，完整演示选题库搭建流程：

**Step 1**：用 AI 生成 10 大方向 → 得到 30 个子话题
**Step 2**：每个子话题扩展 5 个选题 → 得到 150 个选题
**Step 3**：标注选题类型（教程/避坑/对比/清单）和适合平台
**Step 4**：按紧急程度排序，生成 4 周排期
**Step 5**：每周补充热点，淘汰差选题，保持 100 个选题的库存

一个 150 题的选题库，按每周 5 篇计算，可以支撑 **30 周不断更**——大半年的内容储备，一次搞定。

---

**总结**：选题矩阵的核心是"系统化 + AI 批量生成 + 持续维护"。用 AI 做重活（生成、分类、分析），你只需要做决策和创意把关。搭建好选题库，内容创作就从"每天想选题"变成了"从库里挑选题"——效率提升 10 倍不止。
